## 1. 有限探针173类与全未来275类

原报告§33.2明确写出1,464个长度0–3的程序，得到173类。**这一有限窗口计算本身正确。** 需要修正的是§34.3把173写成完整未来等价商的大小：`|H_min| >= |R / ~future| = 173`，以及图86的“Full reasoning states”表述。若`~future`仅指既定窗口，应把窗口写进定义；若指任意未来，等号应为275。173仍可作为一个有效但较松的下界，不能说原来的“至少173”被反例推翻。

原成员：`evidence/experiments/REASONING-BRANCH-021_bundle/REASONING-BRANCH-021.py`。状态是`(goal, main, branch, comparison)`；275合法状态、11动作、读出`(main-goal) mod 5`。本次只执行已经审阅的状态、转移和读出函数定义，不执行原脚本的训练/绘图/文件输出部分。

从当前读出开始，反复把“当前输出及每个动作通向的上一轮等价类”作为签名，直到分区不再变化：

|允许的未来长度|0|1|2|3|4|5|6|
|---|---|---|---|---|---|---|---|
|可区别类数|5|65|105|173|258|275|275|

确定性有限转移系统中，保持读出与所有动作后继的稳定分区恰好给出全未来行为等价。因此该系统全未来类数是275；精确、无限未来仿真所需可区别内部状态至少275，定长二进制编码至少`ceil(log2 275)=9`bit。与25种可见goal×main投影的类数比为11；`log2(11)=3.459`是类数比的对数，未指定概率分布时不称Shannon熵增加。

另用**显式词枚举**独立检查全部1,464个≤3步程序，得到同样173类，并找到四步见证：

- A=`(1,0,5,3)`，branch=5表示未设定；B=`(1,0,2,3)`。
- 对所有≤3步程序，A/B输出相同。
- 施加`R+1 → R+2 → COMPARE → CORRECT`：A最终输出2，B最终输出1。

所以它们不属于同一“全部未来”等价类。原本“相同当前表面并不保证相同后继”的定性主张仍成立，并得到更精确的计数。原先基于3步探针计算的stable rank、维度、89.89%等数值仍应标注3步窗口；本次未把这些几何指标重算为无限窗口指标。

证据：[finite_horizon_witness.json](finite_horizon_witness.json)。见证脚本首轮有一个多余break的语法错误，未执行计算；修复后成功。失败已记WORKLOG，不隐去。

## 2. 短语17.3%不是简单算错

原成员`LANGUAGE-HIERARCHICAL-GENERATORS-017_phrases.csv`有185个短语项，按`n_test`加权：

- composed MSE = 0.1416918541803069；direct MSE = 0.11275949593331115。
- “总加权MSE降低比例”=`1 - mean(direct)/mean(composed)`=20.4192%。
- “逐短语相对改善的加权平均”=`mean_w(1-direct_i/composed_i)`=17.3249%。

报告的17.3%对应第二种合法估计量。建议在数字旁说明分母和权重，而非更正成唯一的20.4%。两种统计回答的问题不同，不能混为同一效应。
