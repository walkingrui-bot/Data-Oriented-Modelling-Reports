## 先给判断

这是一份有实质性小模型实验、数学构造、因果干预和负结果的累积研究记录。最可靠的部分是：**在明确的小型系统中，训练次序能够改变后继计算；相同外显文本或最终答案不唯一决定内部状态与后继作用；可解码信息不等于模型正在使用的信息；固定任务内的即时答案正确率不必随额外步骤单调增加。** 这些主张值得保留。

报告结尾并未完成以下证明：自然语言普遍只有几个控制维度；观察到的低秩残差就是独立的“推理生成元”；小模型发现已推广到真实大模型或人类推理；状态停止器已经带来端到端运行时间收益。结尾对许多边界已有明确限制，评审接受这些限制，不将早期措辞直接算作最终越界。

**需要跨架构复现，但应选机制做，而非把所有历史图表在新模型上机械重画。** 首轮优先检验 §42–44 的 Direct / Blank / 关系 CoT、状态依赖及停止折中。更换模型无法修复有限窗口与全未来的混淆、加权统计口径或训练/测试语料的分割问题；这些先用数学或数据审计处理。

本次已安装官方 Pythia-70M 和 Mamba-130M，并另立了 GRU / 因果 Transformer / Mamba 三架构、各三次初始化的同任务实验。新实验结果与预训练模型实际运行情况见[复现记录](../ML-EPIDEMIOLOGY-XARCH-20260926-001/REPORT.md)。新实验是概念复现，不是旧实验数值重放。

4. oracle first-ready → gold-free stopper；固定CoT长度 → 条件readiness集合。oracle不可替换可部署结果，性能/节约必须成对呈现。

|优先级|问题|合适做法|不充分的替代|
|---|---|---|---|
|P0，已审计|173是否全未来等价类|闭包分区细化至固定点+短词反例|再训练一个神经网络|
|P0，已审计|17.3%及42–44%是什么量|原始CSV、权重、分母和成本边界核对|仅照抄图标题|
|P1，本轮执行|三模式、额外步骤、状态作用跨架构是否存在|相同合成任务、全seed、同课程的GRU/Transformer/Mamba|挑一个答对的seed展示|
|P1，本轮执行|原停止器优势是否易迁移|预固定停止规则、按题分折、与固定步及简单margin比较|查看test后调阈值或当oracle部署|
|P1，本轮兼容检查|官方模型是否能在这台机器读状态和求干预梯度|两官方模型实际加载、前向、梯度、no-op与差分|下载成功就称机制复现|
|P2，尚未执行|训练历史的机制普遍性|匹配数据、优化器状态、起点、训练预算，多seed的次序干预|仅改变最终权重或取top/bottom样本|
|P2，尚未执行|真正比较/分支算法定位|同管线已知正控，任务未见样本，匹配随机patch及有选择的rescue|全final hidden替换或probe高准确率|
|P2，尚未执行|语言低秩/层级算子普遍性|多领域语料，训练集内估计，独立文档测试，full closure与能量噪声对照|只换一个模型或测一个PCA比率|
|P3，尚未执行|自然LLM推理/真实成本收益|原生任务、长度/位置匹配、未见题，含prefill和停止器成本的服务测量|把几枚合成关系token或步数减少直接外推|

最终判断：**有足够证据支持一条严肃的小模型机制研究路线；有必要进行跨架构检验；目前不足以把整套框架升级为自然语言/自然推理的普遍定律。** 本轮具体支持与不支持以新实验全部预定seed的结果为准，不以安装成功或数学恒等式给经验主张加分。
