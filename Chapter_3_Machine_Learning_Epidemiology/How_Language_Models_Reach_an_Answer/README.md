# How Language Models Reach an Answer

Data-Oriented Modelling · Chapter 3, Report 02 · English edition 1.0 · 29 September 2026

The study connects language dynamics, agent working states, protected training and recovery control across 18 experiments. It examines when an answer becomes available, how later steps change that readiness, and how a controller selects a useful intervention.

The controlled recurrent experiments recover readiness for 125/125 aligned exit opportunities using 15 preventive bypasses, 108 local traversals and two reconstructions. The recorded-agent study measures candidate coverage in 300 strong-loop states: 178 have a local k=8 candidate and all 300 have an external candidate. The report defines the separate correctness, coverage and phase outcomes behind these counts.

The report retains 17 scientific result tables, including the integrated results table, and displays all 19 images from the supplied master report. The evidence collection contains 78 unchanged research figures, authored synthetic and derived tables, supporting code and source identities. External raw corpora and provider transcripts are outside the distribution.
