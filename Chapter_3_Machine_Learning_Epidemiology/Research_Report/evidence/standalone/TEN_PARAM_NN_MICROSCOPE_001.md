# TEN_PARAM_NN_MICROSCOPE_001

## Network

Exactly 10 trainable parameters: W(2x2)=4, input weights u(2)=2, bias b(2)=2, output weights v(2)=2.

`h_t = tanh(W h_{t-1} + u x_t + b)`; `z_t = v^T h_t`.

Token encodings are fixed and non-trainable.

## Intervention

- Baseline order: `(00) -> (01) -> (10) -> (11)`
- Swapped order: `(01) -> (00) -> (10) -> (11)`
- The swapped records both have target 0.
- Same initialization, records, learning rate, epochs, loss, and update count.

## Endpoint

Both networks predict all four bare AND questions correctly and with the same hard-label vector: `0,0,0,1`.
