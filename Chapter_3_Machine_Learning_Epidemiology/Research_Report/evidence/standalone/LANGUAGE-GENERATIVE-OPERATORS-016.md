# LANGUAGE-GENERATIVE-OPERATORS-016

## Question

What is language mathematically, beyond the surface meanings of its symbols?

This experiment follows `LANGUAGE-TEACHER-GEOMETRY-015`, which found that the dominant local transition field of the training language is strongly anisotropic and concentrated into a few high-energy directions.

The next question is deeper:

> **What is the object that actually moves along those directions?**

The working hypothesis is that a language unit is not fundamentally a fixed semantic vector. It acts as a **state-dependent transformation** on the current relational/predictive state, and language is generated by composing such transformations.

---

## 1. Operational definition of a language state

For a context `c`, define its predictive state as

\[
q(c)=P(x_{t+1}\mid c).
\]

This is not a neural hidden state. It is measured directly from the training sequence.

If a new symbol `a` is appended, the context changes from `c` to `ca`, and therefore the predictive state moves from

\[
q(c)\rightarrow q(ca).
\]

Define the empirical language operator associated with that event as

\[
T_a:q(c)\mapsto q(ca).
\]

If language units are merely fixed directions, then a token should be well described by

\[
q(ca)\approx q(c)+\Delta_a.
\]

If the token simply resets the system to a token-specific state, then

\[
q(ca)\approx r_a.
\]

If it is a genuine state-dependent operator, a better approximation is

\[
q(ca)\approx A_a q(c)+b_a.
\]

The experiment therefore asks whether the same visible symbol performs different transformations depending on the state in which it is used.

---

## 2. Data and state construction

The same 431,826-character English technical corpus used in experiments 014 and 015 was retained.

Predictive states were estimated for contexts of length 1–5 over the same 64-symbol vocabulary. Reliable context states were retained using count thresholds of 50, 20, 10, 5 and 5 respectively.

All retained predictive distributions were embedded into a common 10-dimensional predictive-state coordinate system by frequency-weighted PCA.

Transitions from context lengths 1–4 were pooled. Contexts were deterministically separated by a hash split: 80% of context identities were used to estimate operators and 20% were held out. The held-out contexts therefore test the transformation rule on contexts not used to fit that rule.

Thirty-five sufficiently frequent symbol operators passed the train/test support thresholds.

---

## 3. A language unit behaves as a state-dependent transformation

Weighted held-out one-step prediction errors were:

| Model of the language action | Weighted MSE |
|---|---:|
| Leave the state unchanged | 0.623272 |
| Fixed token-specific shift `q + Δa` | 0.376802 |
| Fixed token-specific reset `ra` | 0.255918 |
| **State-dependent affine operator `Ta(q)`** | **0.229164** |

The state-dependent operator reduces error by:

- **63.2%** relative to leaving the state unchanged;
- **39.2%** relative to a fixed token displacement;
- **10.5%** relative to a token-specific reset.

Thus the same surface symbol cannot be reduced to one fixed movement vector or one fixed destination. Its action depends measurably on the state in which it is applied.

### First-order Markov control

A surrogate sequence was generated from the empirical first-order character transition matrix. In that world, the next-token distribution is determined by the current last symbol; higher-order history has been removed.

Held-out errors were:

| Model | Markov-surrogate MSE |
|---|---:|
| Token-specific reset | 0.012245 |
| State-dependent operator | 0.011962 |

The state-dependent operator adds only **2.3%** improvement over reset in the Markov world, compared with **10.5%** in the real language sequence.

This provides a direct control: the extra state dependence measured in language is supplied by higher-order linguistic context rather than by the fitting procedure alone.

---

## 4. Language operators compose

If `a` and `b` are consecutive language actions, the operator model predicts

\[
q(cab)\approx T_b(T_a(q(c))).
\]

To test this, both the base context `c` and the intermediate context `ca` were required to belong to the held-out context partition. This produced **866 held-out two-step trajectories**, representing 30,033 empirical occurrences.

| Two-step model | Weighted final-state error |
|---|---:|
| **Correct sequential composition `Tb(Ta(q))`** | **0.273221** |
| Apply `Tb` to the measured intermediate state | 0.264036 |
| Add two fixed token shifts | 0.551509 |
| Use only the final token's reset state | 0.311581 |
| Reverse the operator order | 0.464116 |

Correct sequential operator composition reduces error by:

- **50.5%** relative to adding two fixed displacement vectors;
- **12.3%** relative to using only the final token's state;
- **41.1%** relative to applying the same two operators in the reverse order.

The learned sequence of transformations therefore reconstructs information that is present in the ordered history and is not captured by a bag of token effects.

---

## 5. The algebra is noncommutative

A stronger order test keeps the final symbol identical.

For every sufficiently frequent triple `[a,b,z]`, it was paired with `[b,a,z]`. Both sequences contain the same three symbols and end in the same final symbol `z`; only the order of the first two operations changes.

The divergence between their measured future predictive states was calculated using Jensen–Shannon divergence.

| Sequence world | Matched order pairs | Weighted JS divergence |
|---|---:|---:|
| **Real language** | 587 | **0.394665** |
| First-order Markov surrogate | 1,265 | 0.065930 |

The order effect in real language is **5.99×** the corresponding effect in the first-order surrogate.

Therefore the higher-order language system satisfies, empirically,

\[
T_z\circ T_b\circ T_a
\neq
T_z\circ T_a\circ T_b
\]

for a large set of observed trajectories.

The same symbols, with the same final token, can place the system in substantially different future states solely because their earlier operations were composed in a different order.

---

## 6. How many primitive operators are there?

Each of the 35 learned affine maps was flattened into operator space, frequency weighted, centred, and decomposed by SVD.

The operator family has:

- **stable rank: 6.018**
- participation rank: 11.399
- top-3 operator energy: **41.0%**
- top-6 operator energy: **64.2%**
- top-10 operator energy: **81.8%**
- 95% operator-energy dimension: **17**

This is the crucial separation from experiment 015.

Experiment 015 showed that the **dominant motion field** of local language is concentrated into roughly 2–3 strong directions.

Experiment 016 shows that the **family of transformations acting on that field** is richer. At this character/context scale it has roughly six dominant operator degrees of freedom, with finer structure extending to approximately seventeen modes for 95% of operator variance.

A useful factorization is therefore

\[
T_a
\approx
\bar T+
\sum_{k=1}^{K}\alpha_{a,k}B_k,
\]

where the same operator basis `Bk` is reused across many visible symbols and each symbol selects a different mixture of those basis transformations.

This gives a two-level geometry:

\[
\boxed{\text{few dominant motion coordinates}}
\quad+\quad
\boxed{\text{a reusable operator algebra over those coordinates}}.
\]

The result is analogous to motor control: a small number of effective control coordinates does not imply only a small number of possible movements. Many state-dependent operations can be generated by recombining control primitives on the same low-dimensional moving surface.

---

## 7. Word-level secondary replication

The same construction was repeated one scale higher on tokenized words/punctuation from the same corpus.

Predictive states were represented over the top-128 next-token vocabulary and embedded into a 6-dimensional predictive-state space. Forty-three frequent word/punctuation operators had sufficient held-out support.

| Word-level model | Weighted MSE |
|---|---:|
| Leave state unchanged | 0.125119 |
| Fixed token shift | 0.074128 |
| Token-specific reset | 0.029692 |
| **State-dependent operator** | **0.027684** |

At the word level, the state-dependent transformation reduces error by **6.8%** relative to a token reset and **62.7%** relative to a fixed displacement.

Thus the operator formulation is observed at both the character/context scale and a higher lexical scale within this corpus.

---

## 8. Mathematical definition of language emerging from 015–016

The experiments now support an operational definition stronger than “language is a sequence of symbols” or “language carries meaning.”

> **Language is a state-dependent, compositional, generally noncommutative control algebra acting on relational/predictive states, with discrete surface symbols serving as observable handles for those transformations.**

In compact form:

\[
q_{t+1}=T_{a_t}(q_t),
\]

and an utterance is an ordered product

\[
q_T
=
T_{a_{T-1}}\circ\cdots\circ T_{a_1}\circ T_{a_0}(q_0).
\]

The sequence is not merely a record of meanings. It is a trajectory produced by repeatedly transforming the currently reachable future.

---

## 9. Consequences for familiar linguistic concepts

Under this definition, several familiar concepts acquire direct mathematical forms.

### Meaning

The operational meaning of a unit is its **conditional transformation signature** over the states in which it can act:

\[
\mathcal M(a)=\{q\mapsto T_a(q)\}_{q\sim\mathcal D}.
\]

Two surface forms are functionally close when they induce similar state transformations across the relevant state distribution.

### Polysemy / context dependence

A single visible form can express different effects because the transformation is state dependent:

\[
T_a(q_1)-q_1
\neq
T_a(q_2)-q_2.
\]

The same symbol does not need several unrelated stored meanings; different local effects can emerge from one state-conditioned operator family.

### Grammar

Grammar becomes the set of constraints governing which operators may compose, in what order, and with what consequences.

Because composition is noncommutative,

\[
T_bT_a\neq T_aT_b,
\]

word/order structure is part of the computation itself rather than a cosmetic ordering of already-defined meanings.

### Sentence

A sentence is a **control trajectory through relational state space**.

Its identity is not exhausted by the multiset of its symbols. It includes the ordered path traced by their composed transformations.

### Chain of thought

In the control framework developed in the preceding experiments, a visible CoT supplies additional self-generated operators. Each generated token changes the state from which the next token will be selected:

\[
q_t\rightarrow a_t\rightarrow q_{t+1}\rightarrow a_{t+1}\rightarrow\cdots
\]

CoT is therefore naturally represented as an explicit closed-loop control trajectory rather than a passive transcript of a completed internal answer.

---

## 10. Revised research picture

The combined result of 015 and 016 is now:

\[
\text{surface language}
\rightarrow
\text{predictive / relational states}
\rightarrow
\text{few dominant motion coordinates}
\rightarrow
\text{state-dependent reusable operators}
\rightarrow
\text{noncommutative composition}
\rightarrow
\text{generated trajectory}.
\]

The 2–3 dimensional observation belongs primarily to the **dominant movement geometry**.

The newly extracted basic generative structure is an **operator algebra** living on that geometry. Its dominant operator family is richer than the movement dimension itself.

This resolves an important ambiguity in the earlier hypothesis: a low-dimensional control surface can support a much larger repertoire of language actions because the actions are state-dependent transformations, not fixed axes.

---

## 11. Evidence scope and next scale

The current evidence establishes the operator formulation directly on a 431,826-character English technical corpus, with a held-out character/context experiment, a first-order Markov control, an order-preserving composition test, and a secondary word-level replication.

The next scale is to construct relational states above lexical prediction — syntactic relation states, semantic relation states and reasoning states — and ask whether the same operator basis continues upward or whether new primitive generators enter at specific linguistic layers.

The immediate target is therefore no longer “which words are the primitives?” It is:

> **Which transformations of relational state are primitive, and which higher linguistic structures are products of those transformations?**
