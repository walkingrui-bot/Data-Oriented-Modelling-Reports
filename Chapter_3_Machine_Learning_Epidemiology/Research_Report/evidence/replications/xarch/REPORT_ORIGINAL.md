# 跨架构本机复现终报

research_id: ML-EPIDEMIOLOGY-XARCH-20260926-001；2026-09-26。

**执行：预定9次训练全部完成，另完成两种官方模型的加载、测量及任务筛查。工程：原批次后处理失败，九份终态有效，报告已独立补交。科学：部分支持，部分不支持，范围限于下面的合成任务。**

## 最重要的结果

1. GRU、因果Transformer、Mamba各3次初始化，9/9学会完整关系CoT，9/9直接作答也全对，8/9空白模式全对。因此本任务**不能证明CoT比直接作答更有必要或更优**。
2. 7/9模型有至少一道题出现“正确→错误→正确”的非连通即时readiness集合，覆盖三种架构。支持的是指定提示、读出和路径上的非单调现象，不是所有额外思考都会伤害答案。
3. 固定停止器在5/9模型保持二分类答案全对，但其中1个固定0关系步已经全对；只有4/9同时保持全对且比该模型所有全对的固定深度更省关系步。另4个降至62.5–87.5%。**原报告的停止优势未表现为稳定跨架构结论。**
4. 三种架构对关系token的输入干预都有反应，但Transformer三个seed的答案翻转几乎都来自最后一枚已经含答案的关系token。不能把这种复制/依赖当作比较、分支或纠错算法已被定位。
5. 官方Pythia-70M、Mamba-130M均在本机实际加载并完成前向、续写与梯度测量。然而固定四示例的同类任务筛查，非示例12题的完整CoT正确数为0/12和1/12，均未取得强机制复现资格。安装成功、接口可用与任务机制复现是三件不同的事。

## 原报告与本次的关系

主要复现§42–44末尾的机制问题：Direct、Blank和关系CoT是否有不同作用；即时答案正确性是否随步数非单调；基于当前状态的停止器是否能迁移。原停止实验用六bit和最多5步，本次采用四bit和3个关系token；新停止器是预固定ridge分类评分、阈值0.8，与原实现不相同。故这是**有界概念复现**，未声称重现原seed的42–44%数值；新阴性也不能抹去原固定条件的阳性。

所有16道题均在三个模式的模型训练中出现，每模型共48序列；不存在模型未见题泛化证据。停止器按题8折分组留出，只表示停止器没有用该题的停止标签训练，不等于基础模型没见过该题。独立训练复制单位为seed×架构；144个模型-问题结果不能当成144次独立模型训练。

共同课程：两层、hidden48、900次AdamW更新，seed2601/2602/2603，每次全部48序列、每序列有效生成token平均后等权聚合。GRU29,291参数，Transformer40,523参数，Mamba35,424参数。容量、归纳偏置及优化难度未严格配平，不做架构优劣的因果排名。

## 关系内容干预

每题在完整三关系值前缀中翻转一个bit，保持长度、位置和其余关系值固定，比较最终答案符号。每位置16次干预；no-op全部最大logit差为0。

|架构/seed|翻转r1引发答案翻转|翻转r2|翻转r3（已经是答案值）|
|---|---|---|---|
|GRU2601|7/16|12/16|4/16|
|GRU2602|8/16|8/16|8/16|
|GRU2603|4/16|4/16|12/16|
|Transformer2601|0/16|0/16|16/16|
|Transformer2602|0/16|0/16|16/16|
|Transformer2603|0/16|0/16|15/16|
|Mamba2601|1/16|0/16|14/16|
|Mamba2602|0/16|0/16|12/16|
|Mamba2603|5/16|5/16|12/16|

这证实指定输入内容影响后继输出；但干预可使关系轨迹内部不一致，因而包含离开训练分布的效应。固定后续r3的设计也会挡住r1/r2通过后续token的中介作用。因此0/16不能证明早期关系完全无用，16/16也不能证明独立推理生成元存在。下一次算法定位需要连贯的反事实轨迹、匹配随机对照、恢复实验及任务特异性。

## 两种已安装官方模型的实际结果

权重保存在默认Hugging Face缓存各自唯一snapshot，原件位置、官方revision及环境在[模型索引](MODEL_INDEX.md)。不复制到实验目录。使用CPU fp32、原始安全权重，不量化、不启用远程自定义代码，复用已有环境。

12条固定短英文，每模型都成功进行前向、贪心8token续写、输入embedding梯度和中心差分。Pythia实际70,426,624参数，Mamba129,135,360参数。输入ID与同一原始embedding的no-op误差均为0；全部梯度有限；早期输入方向的自动微分与ε=.01中心差分最大相对差异分别1.141%和0.526%。这是局部测量可用性，未把小误差自动转成语义或算法验证。

## 结论与后续边界

- 支持：有限合成任务内，后继对内容有作用，readiness受状态/路径/读出条件影响，并可非单调；至少这些现象不只出现于GRU。
- 混合：状态停止器在部分seed有折中优势，但跨架构/seed不稳定，候选答案限制和最强固定基线会改变实际意义。
- 不支持本轮升级：CoT在此任务的必要性、可部署端到端节约、通用最优停止、自然语言低维定律、内部比较算法或自然推理同构。
- 尚未检验：模型未见任务泛化、更多语料、精确历史数值重放、完整语言层级closure、真实大模型或人类认知。对两已下载官方模型只完成测量兼容性与资格筛查，未微调。

现在更有价值的是设计直接答案基线不能饱和、又有可验证中间操作的未见问题任务，预先固定资格门及停止器，并把原生输出与实际成本纳入判据；不宜仅继续增加下载模型或在已见16题上调到全对。后续仅为建议，本批已经按固定预算结束，没有自行续训。
