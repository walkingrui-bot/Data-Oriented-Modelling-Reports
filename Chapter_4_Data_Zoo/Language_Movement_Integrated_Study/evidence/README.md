# Authored evidence collection

The five study directories contain recorded derived summaries and the available analysis scripts. `report_tables/` contains the report’s scientific tables and labelled reader annotations; `records/` holds source and evidence identities; `verification/` holds the public-matrix reproduction and integrity results. Figures are in the publication’s `figures/` directory.

Source recordings, provider tensors and participant-level observations are obtained separately. The evidence index and reproduction guide identify the precise numerical object and executable coverage of each study.
