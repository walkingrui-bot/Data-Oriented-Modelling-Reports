# INTOX-SPEECH-CAL-002 — Task-conditioned speech calibration

`ALC_task_conditioned_disfluency.csv` preserves the study’s original transcription of the published 150-speaker ALC summaries. `primary_source_cell_mapping.csv` gives a side-by-side annotation for three values whose task/disfluency mappings differ in primary Table 2 of Schiel and Heinrich (2015), page 28. All three are nonsignificant source comparisons. Use the primary mappings when interpreting those cells. Report Tables 3 and B display both sets explicitly.

Filled-pause and phone-lengthening rates use syllable denominators. False starts, repetitions, word interruptions and unfilled pauses use word denominators. Pause duration is measured in milliseconds. The original source uses generalized linear models.

Primary source: https://www.bas.uni-muenchen.de/forschung/publikationen/IJSLL_SchielHeinrich_2015.pdf
