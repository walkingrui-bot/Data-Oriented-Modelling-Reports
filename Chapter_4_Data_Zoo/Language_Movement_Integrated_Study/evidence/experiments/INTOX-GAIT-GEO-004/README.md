# INTOX-GAIT-GEO-004 — Aggregate gait displacement

`gait_displacement_matrix_soberSD.csv` contains four subgroup-mean displacement vectors and six standardized gait coordinates. Each coordinate is the intoxicated-minus-sober mean divided by the corresponding sober SD. The public matrix retains three decimal places. The source cohort comprises 100 participants; the geometry operates on four aggregate rows.

Recorded SVD summaries, loadings, pairwise cosines and subgroup residual fractions retain the report’s result precision. Figures 6–8 are in `../../../figures/`. The gait script in the adjacent INTOX-GAIT-ROBUST-005 directory replays the distributed matrix.
