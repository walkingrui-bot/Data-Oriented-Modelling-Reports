# CODE-GEOMETRY-005A Evidence Package

Date: 2026-09-27

Controlled matched-semantics programming-language assay. Ten algorithms were implemented in nine languages and parsed with native language tooling. Measurements cover normalized lexical transition geometry, native syntax-tree geometry, a cross-parser canonical semantic skeleton, and simple branch/loop/mutation/type-surface densities.

Languages: Python, JavaScript, TypeScript, C, C++, Java, Go, Swift, Ruby.

Artifacts:
- `results.json`: lexical/native-AST metrics and standardized descriptive distances.
- `canonical_results.json`: canonical semantic-skeleton metrics and Jensen-Shannon distances.
- `code_geometry_005a.py`: primary experiment script.
- `code_geometry_005a_canonical.py`: parser-granularity control/canonicalization.
- `bench.*`: matched task implementations used in the assay.
- `code_geometry_005a_rank_comparison.png`: figure used in the living report.

Primary measured ranges:
- normalized lexical stable rank: 1.342 to 2.485
- canonical syntax-transition stable rank: 1.501 to 2.289

The package records a descriptive structural survey. The later compatibility/transfer phase will test expert partitioning from the measured structural coordinates.
