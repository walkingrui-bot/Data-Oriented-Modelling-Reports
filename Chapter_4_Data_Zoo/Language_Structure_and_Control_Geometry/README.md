# Language Structure and Control Geometry

This language issue examines how narrow local transitions and predicate relations combine into richer sentence structure. Human simplification, multilingual and script controls, response-form comparisons, tool-interface interventions, dependency measurements and a compact relational router provide complementary evidence at different scales.

The report includes all 69 source figures, 79 research and evidence tables, and two additional reader tables. Fifteen separate study archives were recovered. Four studies retain their report results, table transcriptions and embedded figures; their independent analysis archives are not included. Availability is explicit in the evidence index.

The package contains authored reports, controlled experiment materials, derived analysis outputs, figures and source records. External corpus files and provider datasets are obtained from their cited repositories and are not redistributed here. Some recovered scripts require local input paths or code from companion studies.

The relational-router result is a small, consistently directed improvement in reconstructing measured structure from annotated dependency trees at matched feature width. Its scope and the two source-record inconsistencies identified during publication preparation are described beside the relevant results.

Some hypotheses developed in this research have received substantive validation through engineering implementations. Data models are forthcoming.
