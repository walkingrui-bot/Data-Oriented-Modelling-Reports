# CROSS-STRUCTURE-DATA-PASSPORT-PILOT-014A

014A is the first deliberately non-genomic pilot. Four real structures are converted into task-conditioned row matrices and measured with one shared passport interface: the archived 50×38 human genotype panel; the 569×30 Wisconsin Diagnostic Breast Cancer feature matrix; annual sunspot activity transformed into 295 12-lag→3-future windows; and the 34×34 Zachary karate-club adjacency matrix.

Shared fields include row/feature counts, zero fraction, covariance participation-ratio dimension, TWO-NN local dimension, pairwise-distance CV, predictive singular-spectrum r90/effective rank/top-direction share/energy/conditioning, and a common row-split direction-stability probe. The row-split stability field is a measurement-sensitivity probe; for time series and graphs it is not interpreted as an independence guarantee.

The four real structures occupy markedly different measured regimes. Examples: PR dimension fraction is 0.283 for genotype, 0.133 for WDBC, 0.247 for sunspot windows and 0.225 for the graph; predictive effective-rank fraction is 0.329, 0.228, 0.514 and 0.304; row-split effective-support fraction is 0.320, 0.731, 0.899 and 0.160. The pilot therefore establishes that a common measurement contract can expose structure differences before model selection.

Evidence boundary: one dataset per structure is enough to validate the computation interface, not enough to infer universal domain clusters or route model families. The unexecuted EXP014B design adds multiple datasets within each structure and evaluates routing/regret in a separate blind comparison of fixed model families.
