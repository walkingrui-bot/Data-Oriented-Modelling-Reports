# EXP060 报告：真实缺测时跨站与气象信息是否互补

研究 ID `STAT-PSYMOE-EXP060-20261002-001`；2026-10-02；真实自然缺测pair上的传统统计实验。

目标站当前PM2.5在原始CSV中确为NA，但24小时后有本站实测PM。在这个真实任务中，至少8个邻站的同刻PM足以建立一个有用的简单模型：N1邻站分布ridge在2016同站/两整站的MAE分别为47.068/30.531，低于不拟合的邻站中位持续值49.299/34.085。本站气象单通道W1在这两个域均不优于N1。模型只用了训练期3,185个真实站时配对，无人工mask。[方法与冻结门](PLAN.md) · [指标](METRICS.json)。

把本站气象加进N1的联合J1，2016同站MAE降到45.279，相对N1改善3.80%，日区块成对区间支持该域的误差降低。但两座完整留出站的MAE变为30.658，反比N1的30.531略高，区间跨零；事前要求整站也改善≥2%及区间上界<0，因此**联合增量门未过**。2017同站85条也略退化；未来×整站只有16条且J1更差，不用于总体推断。[逐域门](GATE_RESULT.md)。

这回答了架构决策：在当前自然缺测任务，**邻站信息本身有预测价值，但本站气象的联合增量没有在整站条件保持**。应保留更简单的N1基线，不因同站验证一次改善就启用Shared Ganglion。单个线性联合失败不能否定全部空间统计、也不能把模型容量当解释；若继续，应优先找独立城市/时期检验N1，而不是在已经暴露的站点上调J1或NN。

真实缺测原因未知，站×小时强相关；日区块区间只处理当天跨站/相邻行的一部分依赖，不等于独立城市验证。EXP048已用同源2017与整站域做另一任务，后续不可称完全独立确认。实际验证为五域来源逐值复现、目标时间、模型状态与留出逐行预测/MAE/RMSE/区块区间/门的局部8/8核验。未验证外部cohort、缺失机制、临床/环境部署效用、Ganglion、全仓门。原终端输出 (source asset outside this public snapshot) · [关账](CLOSEOUT.md)。
