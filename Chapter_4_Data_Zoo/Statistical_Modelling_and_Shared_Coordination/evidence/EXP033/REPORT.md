# EXP033 Si→Ga 来源转移压力测试报告

研究 ID `STAT-PSYMOE-EXP033-20261002-001`；2026-10-02；`EXPLORATORY_SOURCE_TRANSFER`。EXP032 在 Si 单来源同64人的重复开发划分中看到4/5次冻结统计门通过。本轮按新计划锁定模型方向，在 [PhysioNet GaitPDB v1.0.0](https://physionet.org/content/gaitpdb/1.0.0/) 的 Si 全64人上训练固定传统 logistic，把 Ga 全47人当整来源留出评估一次。官方 [format](https://physionet.org/files/gaitpdb/1.0.0/format.txt) 说明 Si、Ga 是不同原始研究，`_01` 是普通步行、18/19列为两足总力。本研究引用 EXP031 的同一份人级派生特征，不复制或重读原始足底力。

训练 Si 为 PD35/健康29；留出 Ga 为 PD29/健康18。1/1拟合收敛。Ga macro log loss 模型0.519710、Si训练类先验0.697561，改善0.177852；balanced accuracy 0.761494。Ga 的真健康18人中15人判健康、3人判PD；真PD29人中20人判PD、9人判健康。达到事前一次性点估计门。47个保存的个体概率由训练状态重建，指标/门的独立局部复算6/6通过。

本结果说明，在这**两个官方研究的这111份合格普通步行记录**中，固定双足力统计的 Si→Ga 增量未因换研究而消失。它尚不证明模型可用于新中心或新病人：同一资料库的两研究可能有未披露的个人重叠，且采集/入组差异未作因果分解；样本只有47个 Ga 留出人。EXP031 三研究 Ju 数值门失败仍然有效，不能把本轮两研究通过倒填成三研究通过。也没有理由由这个简单统计的通过直接训练 Stat-MoE/Ganglion。

下一步最高价值的证据是核 Ga 与 Si 的受试者独立性、原始研究的来源关系，再找真正独立的新来源或新 cohort。若无法证明，应把本轮保持为来源压力测试而不是确认；不在已看的 Ga 上调整模型。模型唯一状态、优化、预测、局部门和验证器失败/更正均在本目录，见 工作日志 (source asset outside this public snapshot) 与 [门](GATE_RESULT.md)。
