# EXP029 PADS 心算模型外部来源可识别性报告

研究 ID `STAT-PSYMOE-EXP029-20261002-001`；2026-10-02；`EXPLORATORY_SOURCE_AUDIT`。EXP028 的问卷+心算双腕模型只在 PADS 同一开发 372 人的五次人级重分达门，原已看 test 不可转成确认。本轮问是否能在不改变原组三分类、NMS30、双腕传感器和 serial-sevens 静息任务的情况下寻找独立真实人群做直接验证。初始候选搜索已在计划中披露，后续逐源按官方页面审核。

结果见 [SOURCE_MATRIX.md](SOURCE_MATRIX.md)：六个非 PADS 官方候选没有一个通过直接来源门。公开腕部数据 Monipar、BIOCLITE 人数与组别不足；ALAMEDA 只有 11 名 PD。UCI Daphnet 的真实标签是步态冻结事件。PhysioNet GaitPDB 有 93 名 PD、73 名 HC 和部分 serial sevens 双任务，但用足底力传感器、无 DD，也未证实同构 NMS30。PPMI 汇聚大量临床/传感数据，但个体级使用需申请/DUA，适合本模型的逐人通道与组别交集未知。页面未展示的问卷或许可证细节均保留 UNKNOWN，不补猜。没有下载数据、凭据请求或模型运行。

因此直接 M4 外部确认在本轮已审公开源中**不可启动**；EXP028 仍仅是开发候选，不能称外部迁移或临床能力。此停止属于数据兼容/访问与目标不可识别层，不是 M4 在外部测试的表现差。最有信息增益的独立新问题是：利用 GaitPDB 的真实独立人和**不同的足底力传感器**，研究 serial-sevens 认知负荷是否改变 PD 与健康组的运动动力学；它可检验“任务设计比盲目扩大模型重要”的跨场景解释，但须新 ID、自己的来源/样本门和统计比较，不能写成 M4 验证。另一选择 PPMI 要求正式访问申请与许可处理，目前不作为默认下一执行源。
