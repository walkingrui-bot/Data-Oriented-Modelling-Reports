# EXP080 报告：Tetouan三区真实共同时间轴过来源门

[UCI849官方CSV](https://archive.ics.uci.edu/dataset/849/power%2Bconsumption%2Bof%2Btetouan%2Bcity)实际含52,416条从2017-01-01至12-30的严格十分钟记录，九列环境/三区用电完整有限；三区目标均非负且各季度有数千种不同正读数。日期唯一合理格式为月/日/年；按**目标日期**，实际下一小时三区共同配对1–8月34,986、9–10月8,784、11–12月8,640，冻结来源门全通过。[门](GATE_RESULT.md) · 派生矩阵 (source asset outside this public snapshot)。

开始的官方网络504和双空格列名解析误判都保留，只有第三次有效审计用于上述裁决。工作日志 (source asset outside this public snapshot) · [修订](AMENDMENT_001.md)。官方网页实例数52,417，原CSV数据行52,416；没有凭网页数字补一行。源时间只到12月30日，不能说完整2017年；单位/时区及各环境字段实际在线可用时刻未证。三区是不同分区但同一城，不是跨地域独立验证。本ID未训练、未评分验证/测试；局部派生[12/12](LOCAL_VALIDATION.json)。
