# EXP065 报告：本地拟合训练内收益没有在2025 MAE门保持

按已冻结 2024→2025 时间分割，三种普通统计候选在 2024 拟合内都降低了 MAE，但 2025 的 589 个真实缺测配对上，**无拟合 B0 是唯一保留的默认**。B0 MAE 4.094 µg/m³；单一水平校准 C0 为4.159、本地单特征 M1 为4.028、本地八特征 L1 为4.112。M1 仅点估计改善1.62%，日区块差值区间跨零、九个足样本站中四站改善，未过5%/区间/逐站门。C0和L1总体反退化。[冻结门](GATE_RESULT.md) · 派生预测 (source asset outside this public snapshot)。

2024拟合内，C0/M1/L1 MAE 依次4.664/4.488/4.399，优于 B0 5.578；因此单看训练年会得出相反工程选择。2025 结果提供的是**时间泛化止损**，不是容量诊断。L1额外八特征也没胜M1，当前没有证据让 Stat-MoE 或 Shared Ganglion 在这条自然缺测任务取代更简单 B0。与 EXP063 零样本北京参数失败一起，直接跨城和本地当年拟合都没有取得预定的时间外 MAE 资格。[指标](METRICS.json)。

当前仍不知道为何2024→2025增量不稳：目标分布、站点/仪器、自然缺失选择或非线性时间变化可能混合存在，不能凭这两年点成绩下因果诊断。2025 已看，不能重称新确认或调门。下一最有信息增益的选择是**正式暂停此 MAE 任务上的模型升级**，把“简单统计也可能不如零拟合基线”的工程决策写入框架，然后在新 ID 审一个未被反复用于选择的真实任务/损失；若只改 RMSE 或重定任务，须先有新未见时间域，而非拿已看2025补造成功。2026 数据若只有临时/不完整状态，应在来源门停下。[关账](CLOSEOUT.md)。

实际验证：二十原文件源版本与配对数逐站重核，2025派生预测/MAE/RMSE/日区块/门12项复算。未运行NN、Ganglion、全仓门或哈希；不宣称2024/2025实时数据库状态或环境部署资格。原终端输出 (source asset outside this public snapshot)。
