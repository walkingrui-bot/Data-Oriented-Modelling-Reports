# EXP057 报告：扩模型与共享矩阵的真实数据实测

研究 ID `STAT-PSYMOE-EXP057-20261002-001`；2026-10-02；回顾性开发比较，不是药物转化确认。

这次直接在原六路真实target–disease训练/验证数据上训练了九个新模型：原16维B16、只扩大共享核心输出到32维C32、以及接口与核心一起扩大到32维F32，各三seed，同样Adam、学习率、最多2000轮和验证早停。原有源内统计路由、样本拆分和输入不改；验证状态先对旧检查点做精确重建核对，九个训练trace/状态/逐pair验证预测均原位留存。[计划](PLAN.md) · [门](GATE_RESULT.md) · 原始终端输出 (source asset outside this public snapshot)。

**结果：扩大共享矩阵本身没有观察到收益。** C32的三个验证损失均高于同seed B16，差值+0.000330/+0.000016/+0.000130。F32比B16均略低，差值−0.000080/−0.000627/−0.000239；中位只改善0.000239，低于事前0.0010幅度门，≥0.0005改善只有1/3 seed。两支都未过，按预定止损不训练64维。扩大模型不是“零损失”：参数从769升至C32的1057或F32的2049，C32在该验证集还略差。[完整数值](METRICS.json)。

原16维模型在加长到共同2000轮预算后，验证log-loss三个seed约0.198948/0.199316/0.198953，均低于各自旧1000轮成绩；两seed的最优仍在2000轮预算边界。因此实测更支持“先把训练预算与收敛问题查清”，不能据此宣布小矩阵充分，也没有证据为当前任务继续加宽到64。其他候选也有接近预算边界，固定预算比较仍包含优化差异。这是**开发域上的实践止损**，不是更宽模型在未见数据必然无用的裁决。

源状态是Open Targets 26.06当前整理状态，未按历史决策日锁定；原EXP017 test在先前实验已看过，本轮未对其重新打分或用其选择模型。代码把含test行的原cohort全表读入内存后先过滤成train/validation；test标签不参与拟合或评价，但“没有读取任何test标签”的原计划字面表述不准确，保留[执行后更正](AMENDMENT_001.md)。

**实际验证：** 旧验证预测重建、真实train/validation人数与标签、九份状态/trace/逐pair预测损失、同种子1000轮与原trace的吻合、冻结门重算；局部8/8通过。**未验证：** 新外部cohort、未暴露时间/来源测试、decision-date预测资格、充分收敛、64维效果、全仓门。所有结果按真实单位与已看评价边界解释。[局部验证](LOCAL_VALIDATION.json) · [关账](CLOSEOUT.md)。
