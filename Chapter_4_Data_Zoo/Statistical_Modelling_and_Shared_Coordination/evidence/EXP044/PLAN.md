# EXP044 — MyGait PD组内近期跌倒史：步速与双足IMU信息增量

研究 ID `STAT-PSYMOE-EXP044-20261002-001`；2026-10-02；`EXPLORATORY_RETROSPECTIVE_DEVELOPMENT`；父阶段 [EXP043](../EXP043/CLOSEOUT.md)。新科学问题：在真实 PD 个体中，同日附近的舒适速度10米步行双足 IMU，不对称信号是否较临床记录的普通步行速度增加对**过去一个月是否跌倒**的回顾性区分信息？这不是未来跌倒预测、病因识别、外部验证或 Ganglion 资格实验。EXP040 的 PD/健康分类器保持关闭。

## 来源、结果、特征与竞争解释

- 原始单位44名PD中EXP043确认日期/结局有效的40人；组内匿名ID逐人独立。`Participants Data.xlsx` 原件固定列第14 `Number of falls in the last month`；`y=1` 当有限非负整数>0，否则真实0为0。原件问卷日与 `1_10mSlow` 录制日唯一±7天。仅此固定 outcome，不试其他问卷列。
- 传统 M1：同一问卷表第34列 `Average speed 10 m slow`，有限正数取自然对数。它是常规10米步行统计，不是独立任务；用于检验 IMU 是否**超越已有步速测量**。M0为训练折跌倒比例。
- 双足 M2 增加一个事前固定、旋转不变 IMU 特征。每足逐行 `a=sqrt(acx²+acy²+acz²)`，取全任务的 `p90(a)-p10(a)`；`asym=abs(log((disp_left+1e-6)/(disp_right+1e-6)))`。记录原始两侧≥500行、六轴/时间合格证据由EXP037–039原位引用；本轮原件计算并记录读取错误。没有压力量 `p_...`，不作架构搜索或神经训练。

竞争解释：IMU不对称可携带步速之外的跌倒史信息，也可能只反映速度/传感器放置/少数极端人而无额外价值。两种结果决定是否值得在独立队列寻找确认；不以通过开发门替代外部验证。

## 冻结来源门、统计与评价

1. 仅当前40名EXP043有效者可入选。第34列需≥35人有限正数，其中至少8名 `y=1` 且≥20名 `y=0`；源问题不满足则 `STOP_MODEL_SOURCE`，不读IMU。读取这些人全部原 ZIP IMU，若任一访问/数值错误则保留并 `STOP_FEATURE_SOURCE`，不靠替人补样。日期/ID或速度值不推断、不把missing记0。
2. 完整案例人级五折分层交叉验证，五次固定种子 `202610020..202610024`；相同人重复划分仅是开发稳定性，不能算五个独立样本。每训练折单独标准化特征（均值/标准差，零标准差置1）。M1/M2均为**无类别重权**的 L2 logistic（`C=1.0`、`lbfgs`、`max_iter=1000`、`tol=1e-8`），不调参；M0训练折先验。对每重复保留逐人 out-of-fold 概率、收敛状态、宏平均二元 log loss 与阈值0.5的 balanced accuracy。
3. 额外信息开发门：五次中至少4次同时满足 `M1 loss - M2 loss ≥0.02`、`M2 BAcc - M1 BAcc ≥0.05`、`M0 loss - M2 loss ≥0.02`。其他结果记没有观察到稳定附加值；不看结果后改阈值或特征。无论门结果如何只作本40人开发证据，不外推。

## 预算、档案和最小验证

数据步骤≤1次4 MiB ZIP尾部 Range +1次≤1 MiB问卷成员 +最多40次≤1 MiB IMU成员，总≤42请求/≤16 MiB压缩响应，内存读取无原件副本。若来源门停，实际请求更少。派生分析表仅含匿名ID、二元结果、对数步速及双足不对称，不保存原始个人问卷/CSV。五次×5折最多50个统计拟合，CPU本地预算≤15分钟；失败/超时/不收敛保留并停，不以重跑覆盖。输出 `SOURCE_GATE.json`、`ANALYSIS_TABLE.csv`（若可建）、`SPLITS.json`、`PREDICTIONS.csv`、`METRICS.json`、`WORKLOG.md`、门/报告/关账。只核本实验原件 crosswalk、特征、折分与指标，不做全仓门/非必要哈希。
