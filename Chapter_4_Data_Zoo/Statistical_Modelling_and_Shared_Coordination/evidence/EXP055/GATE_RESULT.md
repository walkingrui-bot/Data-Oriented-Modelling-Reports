# EXP055 固定模型容量的本地历史长度门

四城各Q4训练2,007–2,159真24小时对、H2训练4,025–4,165、2014全年训练7,777–8,455；2015同一已暴露评价各7,653–8,526。来源门通过；同一三特征普通ridge/α1在三个窗口分别训练，其他设置固定。一次UCI394原ZIP 3,390,122字节内存/管道读，未复制原数据。2015原始结果由EXP051/052已经看过，故本实验仅探索。

下表各单元为“相对本城持续值MAE改善 / 恢复EXP052两年本地ridge的B0→B2收益比例”；固定门要求**四城均**改善≥5%且恢复≥80%。

| 历史窗口 | 成都 | 广州 | 上海 | 沈阳 | 四城门 |
| --- | ---: | ---: | ---: | ---: | --- |
| 2014 Q4 | 9.42% / 82.5% | 8.13% / 65.9% | 11.95% / 62.0% | 16.22% / 85.1% | 未通过 |
| 2014 H2 | 6.33% / 55.5% | 13.59% / 110.1% | 18.48% / 95.8% | 19.53% / 102.5% | 未通过 |
| 2014全年至12月30日 | 10.60% / 92.9% | 13.43% / 108.8% | 19.69% / 102.1% | 18.58% / 97.5% | **通过** |

首个全四城满足门的固定窗口是2014全年，`ONE_YEAR_HISTORY_SUFFICIENT_EXPLORATORY`。H2成都比Q4更差，说明效应非单调；不能仅凭这组窗口说“样本数量单独造成差异”。但在模型容量不变下增加跨季节历史足以恢复该固定测试上的大部分两年收益，因此没有证据必须先扩大本地模型。此结果**不测试共享矩阵**，亦非未见外部确认。
