# EXP055 — 固定三特征ridge所需的真实本地历史长度

研究 ID `STAT-PSYMOE-EXP055-20261002-001`；2026-10-02；`EXPLORATORY_REUSE_OF_EXPOSED_EXTERNAL_TEST`；父阶段 [EXP054](../EXP054/CLOSEOUT.md)。用户提出模型/共享矩阵可能太小；EXP054短窗增加本地特征自由度反而在三城退化。新问题先固定同一普通模型容量，单独增加真实本地时间覆盖：多久历史才恢复EXP052两年本地模型的2015收益？这能区分样本/季节覆盖与简单参数数目解释；**仍不测试Shared Ganglion矩阵容量**。

## 固定真实单位与窗口

UCI394官方原ZIP内RAR的成都/广州/上海/沈阳各`PM_US Post`，同小时TEMP/PRES与精确24小时后PM2.5；原始单位城市×起点小时。三新训练窗都以2014-12-30 23结束，使目标≤2014-12-31 23，2014-12-31起点隔离：`Q4=2014-10-01..12-30`、`H2=2014-07-01..12-30`、`Y2014=2014-01-01..12-30`。2015-01-01..12-30为同一已暴露评价。EXP054的2014-11短窗B5与EXP052的2013–14全历史B2原位引用作上下界，不重训或复制其状态。缺失PM/气象/目标排除、不插值填零。

## 模型、门和解释

各城、各窗口独立一个 `Ridge(alpha=1.0,fit_intercept=True)`：`log1p(PM_t),TEMP_t,PRES_t`，目标`log1p(PM_{t+24})`，训练窗内标准化、`max(0,expm1(.))`逆变换。无超参选择、来源混合、NN。支持门四城各Q4≥1,500、H2≥3,000、Y2014≥5,000且2015匹配EXP052/B0/B1≥3,000，否则 `STOP_HISTORY_PAIR_SUPPORT` 不拟合。

固定评价：每个窗口在四城2015相同配对上报告MAE/RMSE；以B0持续值和EXP052完整两年B2为参照。每城某窗口要同时较B0 MAE改善≥5%、恢复B2的B0→B2 MAE收益≥80%。依Q4→H2→Y2014顺序，首次四城全过者记 `Q4_HISTORY_SUFFICIENT_EXPLORATORY`、`H2_HISTORY_SUFFICIENT_EXPLORATORY` 或 `ONE_YEAR_HISTORY_SUFFICIENT_EXPLORATORY`；都不过记 `NO_SHORTER_WINDOW_MEETS_GATE`。所有窗口即使失败仍完整报告，不改2015绩效阈值或窗口。2015已先前暴露，结论只能指导后继独立验证设计，不是新确认或2015可部署历史状态。

## 预算与归档

先登记 `EXP055-HISTORY-001`。官方原件一次≤10MiB内存/管道读取，CPU≤10分钟；12个新普通ridge状态合存唯一`MODEL_STATES.json`，逐时预测只存三新窗口和键/真值；旧B0/B1/B2/B5按EXP051/052/054路径引用。保存支持、指标、局部复算、命令返回、门/报告/关账。若全失败，不能直接说矩阵太小；另立ID审历史测量变化或真实独立数据。不跑全仓门/非必要哈希。
