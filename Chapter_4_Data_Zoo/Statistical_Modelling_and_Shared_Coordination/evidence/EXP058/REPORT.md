# EXP058 报告：16维继续训练的实际收益

研究 ID `STAT-PSYMOE-EXP058-20261002-001`；2026-10-02；真实六路26.06数据的回顾性开发优化实验。

EXP057把共享矩阵扩为32维未过预定实用门，但原16维有两个seed在2000轮上限取得最优。本轮固定**同一769参数网络**，让101/202/303三个seed最多训练4000轮，验证patience500；每个重叠的原训练轮次与EXP057 trace数值完全相同，故实测只回答继续训练的收益。[计划](PLAN.md) · 原终端输出 (source asset outside this public snapshot)。

验证log-loss相对2000轮仅改善0.00002986、0、0.00002547；中位0.00002547，0/3达到事先要求的单seed≥0.0002幅度。三seed最佳轮为2369、1783、2246，之后按耐心早停。预定门失败，**不继续在此数据上加epoch**。[门结果](GATE_RESULT.md)。

两轮实测合在一起的工程决策是：这份开发数据上没有观察到值得启动64维的32维收益，也没有观察到继续把16维预算推至4000的实用收益。F32验证点估计略低于B16，但不足原EXP057实用门，保留较小模型与更合适的统计基线作当前参照。不能把这样的开发集止损写成“共享结构已证伪”或“16维绝对够用”。该drug终点无历史decision-date证据锁，test已在旧实验使用，外部确认未建立。

**实际验证：** 真实train/validation支持、旧预测状态重建、重叠训练轨迹完全一致、三份新模型参数形状、保存预测重算损失、门重算，局部8/8通过。**未验证：** 新外部cohort、旧test新评分、历史预测资格、全仓门。全表读取再dev过滤的事实见[EXP057更正](../EXP057/AMENDMENT_001.md)。完整原位[指标](METRICS.json)和[关账](CLOSEOUT.md)。
