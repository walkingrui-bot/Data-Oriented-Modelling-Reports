# EXP034 Ga/Si 来源身份与协议审计报告

研究 ID `STAT-PSYMOE-EXP034-20261002-001`；2026-10-02；`EXPLORATORY_SOURCE_AUDIT`。EXP033 已观察到 Si→Ga 一次整研究留出上的传统统计增量；本轮只问能否将其解释为**可核实的独立受试者外部验证**。审计原件是 [PhysioNet GaitPDB](https://physionet.org/content/gaitpdb/1.0.0/) 的官方格式/人口资料，以及 format 所指 [Ga 原论文](https://physionet.org/content/gaitpdb/1.0.0/#references) 与 [Si 原论文](https://doi.org/10.1186/1743-0003-2-23)。

格式确实把 `Ga`、`Si` 标为不同研究，`_01` 都是普通步行，双足合力同在18/19列、100Hz。两论文的方法也都描述舒适速度约2分钟地面步行与每足8个传感器。但 Ga 的论文为25m走廊、PD H&Y 2–3、30 PD/28健康；Si 为35m走道、PD H&Y 2–2.5、36 PD/30健康。EXP031 官方源精确匹配普通步行的 Ga 为29/18、Si 为35/29。论文人数与本库有效记录的映射没有明示，不能把论文全部受试者硬接到文件。

最关键的是，公开的研究前缀和各自编号没有跨研究全局身份键；原文方法也没有明确说两个样本绝不重叠。两研究由同一中心招募，不同论文/不同编号既不能证明同人，也不能证明非同人。按照预设严格门，**跨研究人员独立性未建立，协议只有部分可比性证据**。这属于外部解释的可识别性限制，不撤销 EXP033 已观察的数值，也不把未识别改写成“真实重复”。

后继应寻找独立发布、受试者来源明确的真实 PD/健康双足信号队列；如果没有同构原件，直接外部确认不可做，应暂停这个解释层。检查的每条证据与缺口在 [SOURCE_MATRIX.md](SOURCE_MATRIX.md)，未训练/重算模型、未下载原始力、未改既有门。
