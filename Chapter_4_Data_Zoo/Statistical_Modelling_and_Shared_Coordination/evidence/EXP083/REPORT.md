# EXP083 报告：滞后天气在真实跨年交通任务中未提供合格增量

**问题。** 单站I-94西向真实小时车流的下一小时车辆数，在本站0/1/24/168小时历史与目标日历外，已完成历史小时天气是否提供值得建立独立环境channel、并在未来年份保持的预测信息？

**实做。** 官方[UCI492](https://archive.ics.uci.edu/dataset/492/metro%2Binterstate%2Btraffic%2Bvolume)原ZIP/GZ仅内存读取；与EXP082原小时来源计数和冲突语义逐项重核。2013–16训练、2017验证、条件式2018留出，完整配对且所有臂同样本，天气用`t−1h`值；两个同规格固定HGB绝对误差模型，PERSIST与WEEK作无拟合描述。仅2017按目标日期≥18小时评估，日等权MAE与2000次成对日期bootstrap。[计划](PLAN.md)事前写明三门与停点。

**观察。** 来源与支持门通过。训练17,090小时配对，验证8,582配对；2017纳入358评价日。BASE/WEATHER MAE 169.703311/169.366289辆，提升仅0.198595%；差区间跨0，51.397%日期改善。PERSIST与WEEK描述性MAE 596.407020/682.654913辆。三项开发门全失败；没有测试分数或跨年收益主张。[派生指标](VALIDATION_METRICS.json) · 原命令输出 (source asset outside this public snapshot) · [门](GATE_RESULT.md)。

**裁决。** 实验执行完成，工程局部有效，科学结论是“本任务当前证据不足以建立额外天气channel”。失败层级为统计增量与跨日稳定性，不是来源支持、模型容量或共享矩阵容量。此站天气线停止；保留BASE为已验证的开发统计对照，但它也没有2018正式评价。原件同小时天气冲突（temp78/rain9/clouds32小时）及本地时区/在线可用时刻未知限制任何应用解释。

**后继。** 多次真实场景追加通道收益不稳定后，下一新ID优先寻找传感器阵列的真实独立测量与时间漂移任务；先审原观测/批次/标签/人或批次独立单位，不直接扩容。若来源过门，再设计传统统计到通道模型的必要性实验。
