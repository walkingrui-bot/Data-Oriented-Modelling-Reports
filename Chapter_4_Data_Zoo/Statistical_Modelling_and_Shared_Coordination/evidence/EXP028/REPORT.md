# EXP028 PADS 心算静息任务真实数据结果

研究 ID `STAT-PSYMOE-EXP028-20261002-001`；2026-10-02；`EXPLORATORY_RETROSPECTIVE_DEVELOPMENT`。EXP027 对单纯静息 `Relaxed` 的联合增益仅 3/5 次开发集重分达到冻结幅度；本轮事先选 PADS 原协议中加入 serial sevens 心算的 `RelaxedTask`，问其真实双腕信号是否在问卷之外更稳定地携带组别信息。它不是随意扫 11 项任务，也不是把 EXP026 已看 test 重新封为确认。

实际读取官方 PADS v1.0.0 原位 372 名原开发人各一份 observation 与左右腕心算任务时序。所有 372 人三类源均可读，1,116 脚本请求加 1 次 preflight、148,530,961 bytes、0 retry；旧 test97 的该任务完全未取。原时序没有本地副本；新派生 `COGNITIVE_FEATURES.csv` 每人保留与 EXP026 完全相同公式的 30 个双腕统计量。问卷特征仅引用 EXP026 原路径，M1/M3 的同折概率仅引用 EXP027 原路径；没有重复复制旧资产。

M4 是问卷+心算任务的相同 class-weighted L2 multinomial logistic，λ=0.1，与此前模型同一开发 372 人、五次预设分层五折划分，25 个 M4 拟合全部收敛。每人每重复一条 OOF 概率。M4 对 M1 的五次 macro log loss 改善为 +0.06167～+0.06966，balanced accuracy 改善为 +0.03433～+0.05906；全部五次同时达到事前 +0.02/+0.03 门，[GATE_RESULT.md](GATE_RESULT.md) 判定开发集信号观察到。M4 对原静息 M3 的 macro loss 五次都改善，balanced accuracy 三次改善、两次下降；所以“心算任务各方面始终胜过静息任务”并未成立。

该结果说明**任务协议可能改变可提取信息**，下一阶段先应验证来源和外部受试者兼容性，再决定是否投资多任务 Stat-MoE；目前没有训练 Shared Ganglion。旧 EXP026 test 的失败依旧有效，因本任务在其后选定，旧 test 不再是独立评价。所有 5 次 fold 重分共享同一 372 人，不能乘作新队列；PADS 只有同中心横断面组三分类，不能回答病程进展、外部泛化或临床诊断能力。问卷与诊断同次采集，评估者盲法仍未识别。

新来源、25 拟合、行级 OOF、五次结果、7/7 局部复核及全部尝试在本目录；没有全仓门、无关哈希或原件副本。下一新 ID 应先寻找有清晰许可、真实独立人、可跨设备映射的外部 cohort；若没有，正式记录外部确认不可识别并保持该模型为开发候选，而不拿同一批人反复“确认”。
