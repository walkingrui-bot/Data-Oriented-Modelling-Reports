# EXP041 — MyGait PD 组内独立临床结果与步态原件 crosswalk

研究 ID `STAT-PSYMOE-EXP041-20261002-001`；2026-10-02；`EXPLORATORY_SOURCE_AUDIT`；父阶段 [EXP040](../EXP040/CLOSEOUT.md)。EXP040 因采集月份缺同期期对照，停止了 PD/健康疾病分类器。本实验另问：同一批 PD 人的双足 `10mSlow` 原件，能否按匿名 ID 与测量日期对齐到**独立的临床连续/计数结果**，为真实人级组内统计问题提供资格？不把源内疾病组标签当新 outcome。

## 固定来源、独立单位与候选结果

固定 44名 PD 原件路径来自 EXP036，数值资格引用 EXP037–039；结果表只读同一 [Zenodo v1](https://zenodo.org/records/15672744) ZIP 内 `Parkinson Dataset/Questionary data/Participants Data.xlsx` 的 `Parkinson Disease` 工作表。README 说表用相同匿名参与者代码。每人只可计一次。选择候选结果顺序在读全表字段之前冻结：

1. 明确的 **MDS-UPDRS/UPDRS Part III 运动检查总分**；
2. 若1缺乏资格，明确的 **Mini-BESTest 总分**（独立临床平衡测评，须确认不是步态 IMU 算法产物）；
3. 若2也缺乏资格，**过去一月跌倒次数**（真实回顾计数）。

不把10m步行时间/速度当独立 outcome，因为它与同一 IMU 任务直接同源；不从很多列挑看起来相关的结果。若仅有MMSE/其他字段，本轮列为下一问题候选，不在本轮事后替换目标。

## 冻结 crosswalk/可识别门

- 从工作表的 `Participant code` 与 EXP036 文件名前缀作一对一对齐；仅允许修剪空格、大小写统一、数字前导零规范化，其他前缀转换须有随包明确规则，否则不作推断。重复行若目标值或日期不同则记冲突并不计人；完全相同目标+日期记录可视为同一人重复观测而不增加样本数。
- 工作表测量日期解析为真实日，与 `10mSlow` README定义的记录日期相差≤7天；日期缺失/不可解析/晚于记录7天以上者不计。后验或当前整理字段不冒充历史预测。所选结果须是独立临床观察、有限数值，至少5种不同值。
- 按上述优先级选第一个满足 **≥30名不同 PD 人**的结果，记 `PD_CLINICAL_CROSSWALK_READY`，只许可另立人级统计模型 ID，不能预称相关或可预测。若无候选满足，记 `STOP_CLINICAL_OUTCOME_SUPPORT`；清楚分辨字段不存在、ID失败、时间失败、重复冲突、数值缺失。

最多1次4 MiB ZIP尾部 Range +1次≤1 MiB问卷成员Range，总≤2源请求/≤5 MiB响应；内存读取，不保存原表或逐人临床原值。保存字段候选、逐人匹配状态/缺失原因和汇总，不复制原件。无模型、无种子。局部验证只核44固定ID、来源列、日期/ID映射和门；不运行全仓门或哈希。无可用结局时继续自治选择其他真实可识别问题。
