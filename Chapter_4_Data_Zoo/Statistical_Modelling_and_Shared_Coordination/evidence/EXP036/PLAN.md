# EXP036 — MyGait 双足 IMU 新数据产品的来源资格

研究 ID `STAT-PSYMOE-EXP036-20261002-001`；2026-10-02；`EXPLORATORY_SOURCE_AUDIT`；父阶段 [EXP035](../EXP035/CLOSEOUT.md)。**不同科学问题**：独立西班牙 [MyGait Zenodo v1](https://zenodo.org/records/15672744) 中，是否能在明确许可与逐人逐足普通步行原件交集下，建立真实 PD/健康双足 IMU+临床表数据产品？不使用不可靠的 `p_...` 压力字段，不试图把 EXP033 牛顿足底力模型搬过去。其 44 PD/45健康、多任务与左右足 50Hz IMU 的公开描述提供可能性，但每任务每足实际交集与许可尚未核。

## 两级门与预算

1. **许可/来源门先行**：只读 Zenodo 正式记录页与其公开 API metadata，确认明确的许可证标识、公开原件 URL、提供者和与 GaitPDB 独立的研究招募；若许可证字段缺失或限制不明，记 `STOP_LICENSE_UNKNOWN`，不读取 ZIP 字节、不训练。不能因网页按钮写“Open”就猜许可。
2. 许可通过后只读公开 ZIP 的中央目录（HTTP Range 从文件尾最多4 MiB，若 Range 不支持或文件列表不可完整解析就停止），**不解压/复制原始数据**。检查 PD与健康各≥30个不同 participant ID，`10mSlow` 每人有左/右足文件、两组至少各80%配对；任务名/组别/ID依官方说明解析，无法确认则 `STOP_FILE_INTERSECTION_UNKNOWN`。若 ZIP 是不可逐项访问的格式或远程只给整包，来源门停止，不绕过预算下载500MB。

只选 `10mSlow` 舒适速度普通步行作为此数据产品的首任务；不把重复试次当独立人。每条时序必须有时间戳/左右足加速度与角速度，后续新 ID 才可数值 QA；本轮不读数值。官方压力 `p_...` 因可靠性问题永久排除本任务。当前页面已有参与者人数、模式、任务等资料，但本轮仍须按来源证据留档。

本轮≤10网络请求、读取正文≤10 MiB、无原始 ZIP/日志/源码副本。输出来源矩阵、分组/任务/足侧文件交集派生表或停止诊断、门/报告/关账。若通过，另立统计问题先做传统模型；若失败，根据失败层自行选择下一真实数据问题。绝不因愿望而降旧 EXP035 力门，也不以 synthetic 结果作正式结论。
