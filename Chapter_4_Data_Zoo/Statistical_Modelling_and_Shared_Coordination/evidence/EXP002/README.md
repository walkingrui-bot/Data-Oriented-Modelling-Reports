# INTERNAL_COORDINATION_002 — Heterogeneous Reality Binding

This controlled experiment tests whether one small system can reorganize three deliberately different observation formats around a shared internal reality when all three are generated by the same hidden simulator mechanism.

Training never receives the simulator latent state. Simulator coordinates stored in `data/reference_simulator_seed123.npz` are explicitly labeled `audit_only`.

## Reproduction

From the extracted package root:

```bash
python code/batch_conditions.py self_only
python code/batch_conditions.py direct_binding
python code/batch_conditions.py switch_binding
python code/batch_conditions.py shuffled_pairing
python code/batch_conditions.py switch_freeze_core
python code/batch_conditions.py switch_freeze_encoders
python code/batch_conditions.py switch_freeze_decoders
python code/batch_conditions.py switch_core_only
python code/trace_seed0.py
```

The reproduction scripts write new outputs into `reproduced_results/` and leave the archived evidence unchanged.

## Main evidence

- `results/all_runs.csv`: endpoint results for 8 conditions × 5 seeds.
- `results/summary.csv`: medians, ranges and joint pass counts.
- `results/seed0_binding_trace.csv`: dense internal trajectory after self-learning is switched to reality binding.
- `results/first_binding_update_5seeds.csv`: first-update localization across five seeds.
- `results/per_source_latent_r2.csv`: post-hoc audit against the hidden simulator state.
- `results/seed0_parameters_pre_post.npz`: complete parameter snapshots immediately before and after binding.
- `figures/`: report figures.
- `protocol.json`: final-batch settings and acceptance criteria.
- `manifest.json`: SHA256 digest and byte count for every packaged file.
