# EXP050 — 独立城市PM2.5逐小时来源与共同特征资格

研究 ID `STAT-PSYMOE-EXP050-20261002-001`；2026-10-02；`EXPLORATORY_EXTERNAL_SOURCE_AUDIT`；父阶段 [EXP049](../EXP049/CLOSEOUT.md)。新问题：EXP048 的北京单城传统统计改进缺外部城市证据；是否存在许可明确、真实逐小时PM2.5结果与气象输入、可构造精确24小时实测配对的独立城市来源，以值得在新实验中评估跨来源运输？本实验只审来源，不训练、预测或看模型绩效。

## 候选与已知不兼容

[UCI 394 官方页](https://archive.ics.uci.edu/dataset/394/pm25dataoffivechinesecitiesUCI)列北京、上海、广州、成都、沈阳五城，2010–2015逐小时、`NA`缺失、CC BY 4.0、PM2.5 / TEMP / PRES 等字段，下载文件为`FiveCitiePMData.rar`。原始单位先按城市×小时，若原件含多个监测点则逐字段保持来源身份，不随意合并。该页 `Iws` 是**累计**风速，不是EXP048的同小时 `WSPM`；因此EXP048八特征保存模型无法原样直移。若来源合格，后继必须用新ID冻结共同特征（本站PM/TEMP/PRES/时相）并重训传统基线；不得将旧模型的WSPM偷换为Iws。

## 固定审计与门

仅官方原档一次网络读取≤10 MiB，在内存或管道列档和解析；压缩工具不可直接管道读取则停止并保存失败，不建立原档副本。逐城市核字段、具体PM测量列身份、时间列与重复小时、数值范围、`NA`与精确`t+24h`真实结果；不把缺失填零、不插值、不用未来气象。审计产出每城/每PM字段的行数、时间范围、完整的`PM(t),TEMP(t),PRES(t),PM(t+24h)`配对数和缺失排除数，且记录原始CSV成员路径和官方元数据出处。

若至少**三个非北京城市**各有≥15,000个上述完整实测配对、唯一可解释小时、至少365天日历跨度、清楚的PM测量字段/城市归属，且许可明确，则 `EXTERNAL_COMMON_SCHEMA_SOURCE_READY`。否则按缺档/软件解析、字段语义、时间/样本支持分别停止。这个来源门不能宣称预测外推。北京城市仅用于污染/源重复排查，不计外部城市数。后继选择应保证源级留出和测试前冻结；若UCI394不满足，另寻真实来源，不降门。

## 预算、输出与停止

一次官方压缩原件网络响应≤10 MiB；CPU≤10分钟；无训练、无需随机种子。先登记 `EXP050-SOURCE-001`。仅保存派生`SOURCE_METADATA.json`、`ARCHIVE_AUDIT.json`、`NUMERIC_SUPPORT.json`、运行返回、门/报告/关账；原ZIP/RAR/CSV不落盘、不复制。局部核原位派生字段和脚本语法，不跑全仓门/哈希。若压缩格式阻断，停止本次研究并保留失败现场，由新ID作工程修复，不把软件失败写成科学来源失败。
