# EXP063 — 北京 N1 冻结参数的独立伦敦区域零样本检验

研究 ID `STAT-PSYMOE-EXP063-20261002-001`；2026-10-02；`EXPLORATORY_FROZEN_EXTERNAL_GEOGRAPHY_TEST`；父阶段 [EXP062](../EXP062/CLOSEOUT.md)来源门通过。新科学问题：北京真实自然缺测配对训练的普通邻站 ridge **N1 原参数不动**，在独立 UK-AIR 2024 伦敦区域同定义 667 配对上，是否优于无拟合的同刻邻站中位数持续值 B0？这直接决定该模型能否跨地理运输；本实验不训练、不调容量或 Ganglion。

## 原件、样本与锁定模型

模型状态只引用 EXP060 MODEL_STATES.json (source asset outside this public snapshot) 的 `N1`、`B0` 定义；不复制检查点、参数文件。N1 八特征顺序、训练均值/尺度、系数、截距、`log1p`/`expm1`、预测非负截断逐项照原文件。B0 为时刻 `t` 可见合格邻站 PM 中位数，无拟合。伦敦数据仅来自 EXP062 SOURCE_MATRIX.json (source asset outside this public snapshot) 固定十个合格站官方 2024 CSV 原链接；再次原位读取，先要求每站原已核定有效小时计数和真实缺测配对总数/每站数逐项等于 EXP062，否则 `STOP_SOURCE_VERSION_DRIFT`、不评分。原 CSV 不另存。

本实验只评 EXP062 的同定义站×小时：目标站 PM(t) **明确空字段**、精确`t+24h` 已核定实测、其它合格站`t`至少八个已核定实测，2024 官方 GMT 小时结束（`24:00` 次日零时）；不插值、不把空当零、不用未来邻站值/未来气象、无伦敦标签拟合。地区框含 BDMP 与 THUR，简称伦敦区域而不称行政大伦敦。EXP062 已读取目标支持数但尚未计算模型外部误差；因此是预定门的外部探索检验，非未接触过来源的盲确认。UK-AIR 当前历史文件不能冒充2024当时实时数据库状态。

## 指标与止损门，评分前固定

- 主指标真实 `µg/m³` 单位总体 MAE；次指标 RMSE、预测/真实均值、十站逐站 MAE；保存每对派生预测与标签仅一份，不存原 CSV。
- `ZERO_SHOT_N1_TRANSPORT_SUPPORT` 同时需：N1 对 B0 总体 MAE 相对改善 ≥5%；以**预测起点 GMT 日**为共同区块（当天全部站行同抽）1000次 bootstrap、seed 20261002，N1−B0 成对绝对误差均值 95% 分位区间上界 <0；十站中 ≥7 站 N1 MAE 小于 B0；任一站 N1 相对 B0 恶化不超过20%。所有条件失败即 `ZERO_SHOT_N1_TRANSPORT_NOT_SUPPORTED`，不在本 ID 调北京参数、后验重定义子群或降低门。
- 日区块仍可能低估连续污染事件相关、空间相关；逐站样本不均衡，故即使门过也只称这批回顾性外部地理样本支持，不称部署资格或历史决策正确性。

执行前尝试 `EXP063-TEST-001`，命令 `python3 score_frozen_n1.py`，≤十个官方 CSV 请求、≤20 MiB、CPU≤15分钟；输出 `SOURCE_RECHECK.json`、`PREDICTIONS.csv`、`METRICS.json`、`RUN_OUTPUT_001.txt`、局部验算/门/报告/关账。原参数与来源均不覆盖，不运行 NN、全仓门或非必要哈希。若门失败，下一问题才是区分*地理基率/尺度转移*与特征关系失效的**新**本地适应实验，且要有训练/测试时间分割；不得据此把本伦敦测试改称确认。
