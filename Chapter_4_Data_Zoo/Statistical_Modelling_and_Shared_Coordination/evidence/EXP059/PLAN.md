# EXP059 — 自然监测缺失时跨站24小时预测的真实来源门

研究 ID `STAT-PSYMOE-EXP059-20261002-001`；2026-10-02；`EXPLORATORY_REAL_SOURCE_AUDIT`；父阶段[EXP058](../EXP058/CLOSEOUT.md)。EXP057/058表明当前药物开发数据上加宽共享矩阵或继续增加16D预算均未过实用门，而历史时锁和新来源支持不足。新科学问题：当**目标北京站在预测时刻`t`的PM2.5确实缺测**，但24小时后真实PM2.5、本站当时气象及其他站同刻污染已观测时，原UCI501是否提供足够站×小时真实样本来研究共享监测信息的独立价值？这研究实际监测缺口，不制造人工mask；新endpoint是原始`t+24h`实测PM，不改以前实验。此轮只做来源与样本支持，不训练。

## 数据与固定资格

官方UCI501原始外ZIP及其中`PRSA2017_Data_20130301-20170228.zip`，来源/许可/12站时钟见[EXP047](../EXP047/REPORT.md)原位档案；一次官方原ZIP网络读取≤20MiB，内存解析，不另存原CSV/ZIP。12站都需各35,064个唯一小时，站名与CSV内标签一致、共同小时精确对齐；否则停。站×小时为行单位但连续小时不独立；未来建模必须按整站/时间对照。

合格自然缺失pair：目标站`PM2.5(t)`原CSV确为NA；`PM2.5(t+24h)`有限且≥0，时间戳精确24小时；目标站`TEMP/PRES/WSPM(t)`全有限；其余11站在`t`至少8个原始有限非负PM2.5。全程不插值、不把NA当0、不用`t+24`其他变量。原日期窗继承EXP048：训练站为非`Aotizhongxin/Wanshouxigong`的10站，训练起点2013-03-01至2015-12-30；同10站验证2016-01-01至2016-12-30；同10站未来2017-01-01至2017-02-27；两个整站2016及2017同窗只作来源支持。日期均以预测起点定义，目标留在同窗的年内。原EXP048虽已报告常态完整pair的2017/整站结果，此处仅审未使用的天然缺测行支持，后续若建模仍仅称探索性同来源迁移，不能把这些域重新命名完全未见外部确认。

事前来源门：训练合格pair≥500、且至少5个训练站各≥20；2016同站验证≥100、至少5站各≥10；2017同站未来≥40、至少4站各≥5；2016两个整站合计≥40且各≥10；2017两整站合计≥10且各≥3。五域缺一则`STOP_NATURAL_OUTAGE_SUPPORT`，不开模型；若全过则`NATURAL_OUTAGE_SOURCE_READY_FOR_DESIGN`，仍需新ID固定传统统计基线、时序相关误差和评价门后才能训练。阈值是能设计初步开发/压力测试的最低来源门，不意味着预测能力或近乎独立样本数。

输出原位`SOURCE_SUPPORT.json`与`STATION_YEAR_COUNTS.csv`（仅聚合数）、方法脚本、原终端输出、门/报告/关账。原始NA/未来缺失/气象缺失/网络支持不足分别计，防止总数掩盖来源失败。计划尝试`EXP059-SOURCE-001`；一次读取，CPU≤15分钟；不为过门调整阈值或补造缺失，不运行NN/Stat-MoE/Ganglion、全仓门或非必要哈希。真实缺失机制及其选择偏差目前未知，不在本来源审计推断缺失随机。
