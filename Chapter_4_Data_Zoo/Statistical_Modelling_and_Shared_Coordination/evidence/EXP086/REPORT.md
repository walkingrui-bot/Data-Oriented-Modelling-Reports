# EXP086 报告：按日气敏原件存在，预冻行数与单调时间门未通过

**问题。** [UCI487官方数据](https://archive.ics.uci.edu/dataset/487/gas%2Bsensor%2Barray%2Btemperature%2Bmodulation)能否提供13个日期实验日、20列同步CO施加浓度及14气敏原件，为后续独立暴露事件识别奠定来源基础？本ID不把时序采样行当样本，也不比较模型。

**实做与观察。** 官方包只在内存读取（183,298,753字节，外ZIP内原ZIP与README）；13个日期文件逐行审数值、缺失、时间、CO范围。均有约295千完整行、13天合计3,843,160，14路和参考字段有限率100%、CO在0–20ppm、每日≥298个六位精度不同数值；2016-10-03出现一处原顺序回退，其他日没有。见派生源矩阵 (source asset outside this public snapshot)和原命令输出 (source asset outside this public snapshot)。

**门与限度。** 总完整行<4,000,000，全部日单调失败；七门5/7，`STOP_CO_SENSOR_SOURCE_SCHEMA_OR_SUPPORT`。[门](GATE_RESULT.md)原样保留。网页的约410万概述不能替换原件数字，回退也不能因为只有一次而在本ID忽略。源支持足以提出新的局部事件识别问题，但不证明每个15分钟暴露可单独分割、CO值可当瞬时独立真值，或任何架构有收益。

**下一问题。** 新ID在明确记录这两个旧失败的前提下，只审原顺序回退的性质与15分钟施加边界是否由原时间/浓度条件实证识别。若不能，不把百万行送进训练。
