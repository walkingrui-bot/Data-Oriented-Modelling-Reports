# EXP046 — 北京多站点真实空气质量时序的来源/数值资格

研究 ID `STAT-PSYMOE-EXP046-20261002-001`；2026-10-02；`EXPLORATORY_SOURCE_AUDIT`；父阶段 [EXP045](../EXP045/CLOSEOUT.md)。EXP045 公开survival事件时间含合成替换；MyGait仅40人且IMU增量0/5。新科学问题：公开的**北京多站点真实空气质量观测**能否提供足够的测站、真实小时序列、PM2.5结果与独立气象通道，以构造有整站/未来时间留出的异质科学预测产品？此应用场与药物/PD路线独立，先让来源决定架构，不先训练Stat-MoE或Ganglion。

## 固定候选、来源门与真实单位

候选为 UCI Machine Learning Repository 官方 `Beijing Multi-Site Air Quality Data` 原始下载及其元数据/引用。先核来源提供者、原始观测而非生成、明确的使用许可、12站/约2013–2017小时任务说明与公开原件 URL；若许可、来源真实性或原始下载不明，记 `STOP_SOURCE_PROVENANCE`，**不读数值**。研究单位是独立监测站×小时，而不是把一站所有小时当独立站；未来模型需时间锁和整站留出。Pollen/其他污染物不在本轮当PM2.5 outcome。

许可/来源通过后，仅按原位ZIP网络流在内存读官方CSV，保留派生索引而不复制原始CSV/ZIP。冻结数值资格：≥10个可辨独立站；每站有≥30,000个唯一合法小时时间戳，无相同站×时冲突；至少10站每站PM2.5有限非负有效小时≥25,000，且 `TEMP/PRES/WSPM` 三基础气象值同时有限小时≥25,000；这些合格站的原始小时网格共同重叠≥20,000小时。未观测PM2.5保留缺失，不能当0。过门 `REAL_MULTISITE_SOURCE_READY`，否则 `STOP_NUMERIC_SOURCE_SUPPORT`；未过不训练、不得调小门或只挑表现好的站。

## 预算和输出

官方元数据≤3页面/API请求；若许可通过，官方 ZIP 原件≤1次≤20 MiB网络响应，内存解压一次，不落本地原件。无模型/种子。输出来源说明、每站行/缺失/时序派生表、门/报告/关账；失败也留原访问/解析诊断。局部验证只核本站数据产品，禁止全仓门或非必要哈希。若门过，下个独立ID冻结传统时间/站点基线再测渠道是否提供增量，不能把来源通过当模型成绩。
