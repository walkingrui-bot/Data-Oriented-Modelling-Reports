# CoT relational-geometry pilot 01

## Question
Treat visible chain-of-thought / reasoning text as a time-indexed language projection and measure it with the pre-existing language-relation geometry coordinates rather than interpreting its semantic claims.

This pilot does **not** assume that CoT reproduces ordinary-language geometry. It asks whether reasoning traces exhibit systematic *transformations or couplings* in the same coordinates.

## Existing coordinates reused
- recurrence density
- local recurrence (gap <= 8)
- mid recurrence (9–24)
- long recurrence (>24)
- recurrence-gap CV
- local bridge
- repeated bigram/trigram density
- 8-bin burst CV

Secondary exploratory quantities:
- recurrence-scale entropy
- recurrence-bin entropy

## Public data
ChainScope raw response archive:
- DeepSeek-R1 vs DeepSeek-chat
- 16 matched world-model prompt sets, two independent 8-prompt batches
- 400 usable R1 traces and 321 usable chat traces for 64-token normalized-window analysis
- fixed-lag control restricted to >=96 content words: 398 R1, 50 chat
- independent model-family check: 14 long QwQ-32B-Preview Putnam traces

The analysis uses content-word tokenization and fixed-length windows. Absolute metric levels should not be equated with earlier genre experiments because the source domain/tokenization differs.

## Main findings

### 1. Reasoning traces are not simply "more repetitive language"
Across all 16 matched DeepSeek prompt sets, R1 had lower recurrence density, lower bridge, and lower repeated bigram/trigram density than DeepSeek-chat.

At the same time, R1 had higher burst CV on 14/16 prompt sets and lower recurrence-bin entropy on 14/16. Thus recurrence in R1 is less globally frequent but more episodically concentrated.

### 2. The stable dynamic signal is a redistribution of recurrence scale
Raw early-to-late trajectory averages:

- DeepSeek-R1: local +0.0784, mid -0.0355, bridge +0.0380, burst CV -0.1180.
- DeepSeek-chat: local +0.0033, mid +0.0199, bridge +0.0023, burst CV -0.0414.
- QwQ: local +0.1181, mid -0.1227, bridge +0.0338, burst CV -0.0561.

The strongest shared reasoning-model pattern is therefore not total recurrence. R1 total recurrence increases; QwQ total recurrence slightly decreases. Both nevertheless shift recurrence from the mid range toward the local range late in the trace.

### 3. Frequency-preserving shuffle control
After preserving the exact word multiset and shuffling positions, the early-to-late **local recurrence surplus** still changes:

- DeepSeek-R1: +0.0504
- DeepSeek-chat: -0.0120
- QwQ: +0.1108

Mid-range surplus:
- DeepSeek-R1: -0.0639
- DeepSeek-chat: +0.0568
- QwQ: -0.1278

Burst-CV surplus:
- DeepSeek-R1: -0.0390
- DeepSeek-chat: +0.0055
- QwQ: -0.0799

Thus the localisation shift is not explained only by greater word repetition.

Bridge surplus is less universal:
- R1: -0.0077 in the pooled fixed-lag subset
- chat: -0.0307
- QwQ: +0.0275

So bridge growth should **not** yet be claimed as a universal CoT law.

### 4. Fixed-token-lag movement control
The initial large difference in "geometry speed" was partly caused by reasoning traces being much longer, making uniformly spaced windows farther apart.

With identical 48-token windows separated by 24 tokens:
- pooled DeepSeek-R1 early speed: 2.943; late: 2.672
- pooled DeepSeek-chat early: 2.817; late: 2.743
- QwQ early: 2.204; late: 2.551

Therefore **tempo is model-specific**:
- R1 tends to slow;
- QwQ tends to accelerate.

The shared signal is not one universal speed curve.

## Current interpretation

The first robust candidate relation is:

> explicit reasoning traces undergo a phase-dependent reorganisation of recurrence geometry, with late reasoning preferentially converting mid-range recurrence into shorter-range recurrence, while recurrence bursts become less concentrated over time.

This is compatible with a transition from broader exploratory relational motion toward locally coordinated / settled packets, but the data are only language projections and do not establish the hidden mechanism.

A simple scalar "lower entropy = more reasoning" theory is not supported. Different entropy-like quantities move differently. A more plausible hypothesis is **local concentration plus temporal movement**: active relation packets can be locally organised while the trajectory across time continues to explore and redistribute activity.

## Important negative/limiting results
- Total recurrence does not move in the same direction across reasoning models.
- Geometry speed does not move in the same direction across reasoning models.
- Bridge surplus is not yet universal.
- DeepSeek-chat traces are much shorter; fixed-lag controls substantially reduce the apparent speed difference.
- These are visible reasoning projections, not direct hidden-state observations.

## Next useful test
If continued, the strongest test is not another surface-style comparison. It is to test whether the same late localising / de-bursting transformation appears:
1. across more reasoning-model families,
2. conditional on success/failure,
3. in hidden-state or activity-field trajectories when available,
4. and in the new AIA/CEG system once it begins producing language.
