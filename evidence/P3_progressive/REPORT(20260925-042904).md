## 实际执行

首轮TRAIN-001的三个成熟度门均失败（验证约35%/36%/44%）。按事先预算接续TRAIN-002，继承各自model/AdamW/RNG并重启同一学习率日程。首轮数据完整保留；后续评估使用另一个事先固定的数据种子。ANALYSIS-PREFLIGHT-001曾因带噪声的小样本probe夹具失败，原输出与重建源码保留；修订为无噪声索引夹具后通过，不改科学probe配置。

从零实现十符号、64维、3层、4头、4倍MLP、learned position、pre-LN causal Transformer，155456个参数。每个episode在线随机产生8条证据，各以0.3概率改成错误类别。隐藏规则从未进入输入；训练只监督 ANS 后的答案 token，不监督 THINK 或规则 b。三个种子41/42/43，每个累计24000次更新、batch128；各THINK数量均匀抽样且共享权重。采用TRAIN-002预先指定的最终检查点。

完成全部训练后才检查验证结果。机制阶段参数全部冻结；线性probe在独立训练episode上拟合。三个独立训练种子是模型层面的重复；不同层、位置、head与bootstrap不算独立模型。

本次学习预算为三seed累计72000个optimizer step、9216000个在线episode。主模型基本能力未达预写成熟度门，因此后续机制测量只作描述，不能用来否定一般假说。未进一步诊断本次学习不足的根因。

## 机制链证据

- Level1：各seed共同具有高于机会水平probe信号的末步位置 0 个。
- Level2：同一位置类型在三个seed均显示准确率提高、CE下降、熵下降（1→8的配对区间）的 0 个。
- Level3：单THINK不同规则状态替换在三个seed均有至少1个百分点概率作用：False。
- Level4：末步单THINK替换在共同layer/type满足operator增量≥.05、优于donor答案、same-rule和随机控制的 0 个。
- Level5：NOT_ESTABLISHED。需同时满足成熟度、THINK收益、同位点熵/CE/准确率轨迹及operator早晚增强。

这些是预先写明口径下的探索性统计；扫描多个site后的个别区间不具有全家族确认意义。没有可重复THINK计算收益时，即使某次移植有效，也不授予渐进规则形成结论。Probe熵是所拟合线性分类器的预测不确定性，不是对内部状态真实后验熵的精确测量。

固定三层限制依赖链深度。THINK之前没有query，相关状态不能直接含有donor后续query的答案；最后一层block-output THINK态也不能再影响未来答案。本实验同时验证了这两个因果边界。不同THINK数量改变绝对位置；位置保持的屏蔽控制用于限制这种混杂，单纯数量相关性不够。
