# Frozen-weight latent-rule fitting — mechanism pilot 02

Date: 2026-09-25

## Question

After model weights are frozen, can a Transformer infer a task-specific generative rule from relational evidence, instantiate that rule in runtime state, and causally use it to generate future states?

This experiment treats visible reasoning outputs and routing states as intermediate phenotypes rather than as the mechanism itself. The target is the upstream process that converts evidence into a task-specific executable rule.

## Controlled latent-rule task

Five visible states are used. Each episode samples a hidden cyclic transition rule

\[
y=(x+b)\bmod 5,
\]

with episode-specific \(b\in\{0,1,2,3,4\}\).

The prompt does **not** state \(b\). It provides two randomly sampled input-output examples generated by the rule, a query start state, and a requested rollout length. The same fixed-weight 3-layer decoder-only Transformer must infer the hidden rule and generate the rollout one state at a time.

Model: 3 layers, d_model=64, 4 attention heads.

After training, in-distribution rollout accuracy was:

| requested steps | final accuracy | token accuracy | exact-chain accuracy |
|---:|---:|---:|---:|
| 1 | 0.99 | 0.99 | 0.99 |
| 2 | 0.99 | 0.99 | 0.99 |
| 3 | 0.99 | 0.99 | 0.99 |
| 4 | 0.97 | 0.97 | 0.97 |
| 5 | 1.00 | 1.00 | 1.00 |

Thus the mechanism analysis is performed on a system that reliably learned the latent-rule task.

## 1. Rule information appears only after contextual relational reading

The last visible prompt token (`A`) is identical across episodes and appears at the same position. Predicting the hidden rule \(b\) from its internal state gives:

### At the fixed `A` token

| layer | raw q/k/v | attention pattern | attention readout (hc) | block output |
|---:|---:|---:|---:|---:|
| 0 | ~0.21 | 0.373 | 0.297 | 0.315 |
| 1 | ~0.29–0.30 | 0.471 | **0.760** | **0.740** |
| 2 | ~0.66 | 0.545 | **0.811** | **0.811** |

Chance is 0.20.

The raw layer-0 q/k/v state of the fixed token contains no useful rule information. Rule information becomes available after contextual attention reads the relational evidence and is then carried into deeper runtime state.

### At the final evidence token

The same pattern is even sharper:

| layer | raw q/k/v | attention pattern | attention readout (hc) | block output |
|---:|---:|---:|---:|---:|
| 0 | ~0.21 | **0.602** | **0.651** | **0.667** |
| 1 | ~0.53–0.57 | 0.667 | **0.992** | **0.959** |
| 2 | ~0.80–0.84 | 0.652 | **1.000** | **0.983** |

This localizes the first strong rule-forming event to contextual reading of the evidence relations, not to token identity itself.

## 2. Upstream causal path in the explicit-rule pilot

Before moving to latent rules, the previous explicit transition-table model was decomposed as an upstream mechanism chain.

At the fixed scratchpad token, layer-0 q/k/v next-state probes were only ~0.21–0.22, while:

- layer-0 attention pattern: 0.527
- layer-0 attention readout: 0.750
- layer-1 attention readout: 0.875

Donor causal patching across the scratchpad gave:

- layer-0 contextual output patch: 23.7% exact donor-target redirection
- layer-1 attention-readout patch: **84.1%** exact donor-target redirection
- layer-1 MLP-output patch: **0%**

One layer-1 attention head alone produced a 50.2% donor-target redirection rate.

A mediation test then patched donor layer-0 contextual output while clamping layer-1 K back to the recipient state:

- donor layer-0 output alone: 23.7% donor-target redirection
- + recipient layer-1 K clamp: **10.5%**
- + recipient layer-1 V clamp: 23.1%

Thus, in that model, a substantial fraction of the upstream contextual-read effect is mediated specifically through the next layer's K/routing geometry.

## 3. Latent rule can be transplanted as an operator, not merely as an answer

The strongest test distinguishes answer transfer from operator transfer.

Recipient and donor episodes have different hidden rules and different query start states. Only the donor's contextualized **evidence representations** are inserted into the recipient. The recipient's visible query start state remains unchanged.

If the intervention transfers an answer, the model should emit the donor's own next state.

If it transfers a generative operator, the model should emit:

\[
(\text{recipient start}+b_{donor})\bmod 5.
\]

Patching all four layer-0 contextualized evidence outputs produced:

- recipient prediction flipped: **83.0%**
- exact donor-own answer: **10.8%**
- exact donor-rule applied to recipient start: **51.2%**
- recipient-target probability change: -0.816
- transplanted-operator target probability change: +0.496

The intervention therefore transfers a substantial rule-like computation rather than simply copying the donor's answer.

## 4. The rule is distributed across the evidence relation

Layer-0 contextual evidence-state transplant, separated by evidence location:

| transplanted positions | operator-transfer accuracy |
|---|---:|
| first x only | 0.038 |
| first y only | 0.193 |
| second x only | 0.103 |
| final y only | 0.135 |
| first pair | 0.230 |
| second pair | 0.285 |
| all evidence positions | **0.510** |

No single token is the rule store. The executable rule emerges from a distributed relational configuration across the evidence positions.

## 5. Same-rule control

Replacing the recipient's evidence state with another episode generated by the **same** hidden rule preserved recipient correctness in 70.5% of cases.

Replacing it with a **different** rule reduced recipient correctness to 18.0% and produced the transplanted operator answer in 52.0% of cases.

Thus the causal effect contains a strong rule-specific component beyond generic activation replacement.

## 6. K/V mediation in the latent-rule task

Donor layer-0 evidence output gave 51.2% operator transfer.

Clamping the next layer's evidence K or V back to the recipient reduced operator transfer to:

- recipient layer-1 K clamp: **20.4%**
- recipient layer-1 V clamp: **26.0%**

Both routing and carried content participate in passing the inferred rule forward, with K providing the stronger block in this intervention.

This differs usefully from the previous explicit-rule scratchpad experiment, where K dominated and V replacement had almost no direct causal effect. The inferred rule is first assembled from evidence content and then increasingly expressed as routing geometry downstream.

## 7. A low-dimensional rule component exists, but is not the full executable mechanism

Across many episodes, layer-0 contextual evidence states were averaged by hidden rule. The between-rule centroid space has four nonzero dimensions, with singular-variance fractions approximately:

- 0.424
- 0.260
- 0.244
- 0.071

A recipient state was then moved only along the mean direction

\[
\mu_{b_{donor}}-\mu_{b_{recipient}}.
\]

This caused a dose-dependent reduction in recipient-rule probability and increase in donor-operator probability. At scale 1.5:

- recipient accuracy: 0.584
- donor-operator argmax accuracy: 0.158
- donor-operator probability change: +0.150

A deliberately wrong rule-direction control at the same scale produced only +0.034 operator-probability change.

Therefore a low-dimensional common rule component is causally present. Its effect is substantially weaker than transplanting the real relational evidence state, showing that the executable rule remains coupled to evidence-specific contextual geometry rather than collapsing to one clean scalar/vector biomarker.

## Evidence-supported mechanism after pilot 02

In this controlled frozen-weight Transformer, the data support the following causal sequence:

\[
\text{relational evidence}
\rightarrow
\text{contextual attention read}
\rightarrow
\text{distributed evidence-state reorganization}
\rightarrow
\text{deeper K/V routing state}
\rightarrow
\text{task-specific generative operator}
\rightarrow
\text{next generated state}.
\]

The hidden transition rule is absent from the identity of any single token. It is inferred from relations among evidence tokens, becomes highly decodable after contextual attention, and can be causally transplanted so that it acts on a new recipient state.

The mechanism is therefore more specific than "CoT contains a dynamic biomarker": a fixed-weight network can construct an episode-specific executable rule in runtime relational state.

## Next test

The next strongest experiment is to remove direct input-output examples and require the rule to be inferred from a longer noisy trajectory or second-order recurrence. The target is to measure whether the rule representation sharpens over repeated external write/read cycles and whether destroying the temporal order of those cycles selectively destroys the inferred operator.
