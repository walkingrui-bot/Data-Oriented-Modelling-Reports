# 动态生成规则理论：反例压力测试 Round 2
日期：2026-09-25

## 0. 统一浅名

- current snapshot → 当前局面
- history-conditioned continuation → 来路效应
- selective causal participation → 历史发言权
- continuation law → 下一步规则
- continuation geometry → 下一步地图
- rewrite phenotype → 改路方式
- projection feedback → 自我回写
- reference drift → 地图漂移
- stable anchor → 固定路标
- rule-fitting state → 临时规则状态 / 规则成形

这轮不继续堆支持性表型，而主动尝试打掉三个可检验命题。

## 1. 实验世界

历史序列由 3 类通道组成，每个事件携带 0/1 值；序列末尾给出一个查询通道。目标是输出该通道最近一次出现时携带的值。

因此：
- 当前查询本身不含答案；
- 大部分历史位置与当前答案无关；
- 同一通道较早记录已经过期；
- 保持全部材料不变、只交换两个相关事件的先后顺序，可以改变正确答案。

三种序列架构各 3 个 seed：GRU、简化 SSM、1-layer causal Transformer。另有完全不看顺序的 bag baseline。

三种序列模型独立测试准确率均为 100%。

## 2. 反例刀一：历史是不是其实都差不多有用？

如果改真正相关的历史位置，与改过期历史或其他通道历史，对当前输出影响相近，那么“历史发言权”失败。

干预后输出分布 TV：

| 架构 | 真正相关历史 | 过期同类历史 | 其他历史 |
|---|---:|---:|---:|
| GRU | 0.9969 | 0.0011 | 0.0010 |
| SSM | 0.9824 | 0.0047 | 0.0061 |
| Transformer | 0.9990 | 0.0003 | 0.0001 |

真正相关位置翻转后，三个架构都 100% 跟随新目标翻转；过期或无关历史几乎不动输出。

反例没有成立。

浅显结论：历史不是一锅粥。当前问题会让一小部分过去真正“说了算”。

而且 GRU / SSM 没有 Transformer attention，仍然出现同样锋利的历史发言权。

## 3. 反例刀二：会不会只需要历史材料，不需要来路顺序？

严格 paired test：
- 当前查询相同；
- 历史事件多重集合完全相同；
- 只交换查询通道最后两个、且值不同的事件顺序；
- 正确答案因此必然翻转。

| 架构 | 原序列正确率 | 交换后正确率 | 输出是否跟着翻转 |
|---|---:|---:|---:|
| GRU | 1.000 | 1.000 | 1.000 |
| SSM | 1.000 | 1.000 | 1.000 |
| Transformer | 1.000 | 1.000 | 1.000 |

完全不看顺序的 bag baseline 在普通随机测试上还能得到约 71.1%，但进入成对反例后只有约 50% 正确，而且交换顺序时 0% 改变预测。

反例没有成立。

浅显结论：来路不等于“过去出现过哪些材料”；形成顺序本身就是生成条件。

## 4. 反例刀三：Transformer attention 权重是不是就等于历史发言权？

这一刀真的找到反例。

对 Transformer 每个历史位置：
- 记录 query 对该位置的 raw attention weight；
- 独立翻转该位置；
- 测输出分布变化，作为实际因果影响。

3 seed 平均：
- raw attention 与因果影响 global Spearman ≈ 0.606
- sample 内平均 Spearman ≈ 0.656
- 因果影响最大的位置 100% 是真正相关历史
- attention 最大的位置只有 90.6% 命中真正相关历史
- 约 16.2% 的“高 attention”位置，实际干预效应仍小于 0.001

因此字面命题：

attention weight = causal importance

被直接否掉。

更准确的版本是：

历史发言权是架构无关的因果对象；Transformer attention 是实现这种选择性路由的一种机制和可见投影，但单个 raw attention weight 不是历史发言权本身。

## 5. 当前理论骨架的人话版

1. 当前局面：系统眼下站在哪里。
2. 来路：它怎么走到这里。
3. 历史发言权：过去哪些东西现在真的能改变下一步。
4. 下一步规则：当前条件下接下来怎样走。
5. 下一步地图：各种可能后继现在分别有多容易。
6. 改路方式：当前发生的事情会怎样改下一轮地图。
7. 自我回写：系统刚说的话又回来改变下一轮。
8. 地图漂移：系统一路生成，连“哪里算正确方向”也被自己的历史带偏。
9. 固定路标：不替系统选路，只防止整张地图被自己的历史改坏。

## 6. 这一轮对可信度的意义

不是“又多三个支持点”。

而是：
- 一个反例没打中：历史影响不是均匀的；
- 一个反例没打中：顺序不是可以丢掉的表面信息；
- 一个反例真的打中了：raw attention weight 不能直接等同于实际因果发言权。

所以理论反而变窄了：

历史发言权 != attention weight

但 Transformer attention 可以是实现选择性历史参与的一种机制。GRU、SSM 使用不同内部介质，也能实现同样功能。

## 7. 下一轮真正危险的反例

A. forged upstream history
检验中层注入状态是否可以由某条正常上游输入历史近似重建，而且两者是否产生相同后续动力学。

B. 规则成形是否真的需要动态变化
尝试构造一个完全静态、没有临时规则变化的系统，在同样复杂、同样历史依赖的任务上仍然完成所有功能。如果能做到，“规则成形”只能算机制族中的一种实现，不能当必要条件。

C. 自我回写是否真的造成地图漂移
在真实自回归模型里只改变早期一小段仍然局部合法的输出，测后续生成约束是否发生系统性漂移，而不只是文本表面不同。
