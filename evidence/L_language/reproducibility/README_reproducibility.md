# Reproducibility roadmap

This archive intentionally does not redistribute large or copyrighted raw datasets. `sources/source_index.csv` contains exact public sources. Derived tables in `tables/` are the numerical evidence generated during the research line.

Recommended publication-grade reruns:

1. **Multilingual geometry:** fetch full UDHR/Python parallel materials and several independent parallel corpora; rerun character, word/morpheme, and entity-coreference representations.
2. **Transformation invariance:** replace manually produced translations/modernizations with independent published human translations wherever possible.
3. **Eye movement:** run the gate/target/reinstatement decomposition on full OneStop and MECO; preregister canonical regression definitions and nuisance controls (word length, frequency, surprisal, line position, subject/text random effects).
4. **Bidirectional Chinese:** test whether the same sequence-relative relation model predicts horizontal and vertical regressions after physical x/y coordinates are rotated out.
5. **Neural reinstatement:** use ZuCo/EEG after gaze event detection to test whether neural activity at a selected old relational packet is reinstated at regression time.
6. **Genre/author:** rerun six styles with >=5 independent authors/sources per style, equal-length sampling, nested author/text random effects, and same-source multi-translation controls.

Core falsification target for the NN hypothesis:
- no teacher address;
- a delayed unresolved relational trace must survive;
- when processing cost is low, a distributed old-state affinity field may emerge;
- competition/settling must select a useful old packet;
- credit is assigned to the reinstatement episode, not to globally frequent packets.
