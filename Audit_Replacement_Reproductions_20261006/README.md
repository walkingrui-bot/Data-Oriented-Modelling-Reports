# Replacement Reproductions — Audit Rebuild 2026-10-06

This directory is an audit rebuild for experiments whose original execution chain is incomplete, source-dependent, or only partially replayable in the publication snapshot.

## Scientific rule

A replacement replication is **new evidence**, not a claim that the historical experiment itself has been rerun. Historical reports, numerical tables, figures and source identities remain unchanged. Each replacement asks the same mechanistic question with a fresh, self-contained execution path.

The replacements use generated or fully specified controlled data so that the complete chain is present in the attached runnable bundle:

**data generation → model/analysis code → fixed seed → result file → acceptance gate**.

No replacement result should inherit the original experiment's sample identity, model identity, provider identity, preregistration status or numerical values.

## Historical mapping

`REPLACEMENT_MAP.csv` links each replacement to the historical experiment or report whose execution chain motivated the rebuild. The mapping is claim-level rather than numerical. A replacement can support the same mechanism without reproducing the historical value.

Empirical claims tied to a particular external corpus, participant sample, pretrained model revision or provider trajectory remain tied to their original source records unless separately rerun on those sources. A controlled replacement does not convert a dataset-specific historical observation into a new empirical replication of that dataset.
