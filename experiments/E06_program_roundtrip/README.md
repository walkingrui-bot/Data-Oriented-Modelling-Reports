[Experiment index](../README.md)

## Method

Four small program families and three refactored versions were passed through program/explanation round trips. Exhaustive or dense input-domain execution checks assessed program equivalence, and multilingual explanations were analyzed for relational geometry.

## Interpretation

Across four program families, 229014 execution comparisons preserve program semantics over the tested input domains. Their explanations also carry measurable relational structure.
