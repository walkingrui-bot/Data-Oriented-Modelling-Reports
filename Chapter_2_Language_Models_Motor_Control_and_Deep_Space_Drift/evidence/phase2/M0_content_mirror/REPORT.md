# 硬镜像上下文微型实验

日期：2026-09-25

## 问题
测试一种“硬镜像”上下文构造是否能抵消模型递归吃自己输出时的分布漂移。

## 模型
- 4 层 causal Transformer
- hidden size 32
- 4 heads
- 上下文窗口：31 个二元 token
- 训练任务：每条序列来自一个隐藏 Bernoulli 参数 p，模型学习从上下文估计下一 token 分布。

## 三个条件
每轮都向上下文加入相同数量（16 个）的新 token。

1. **只吃自己**：16 个 token 全部由模型自身自回归生成。
2. **随机中性块**：先生成 8 个自身 token，再加入 8 个 p=0.5 的随机 token。
3. **硬镜像块**：先生成 8 个自身 token；若其中有 k 个 1，则第二段严格加入 8-k 个 1，使两段合计恰好保持 50/50。镜像段内部顺序随机。

初始上下文接近 50/50。每个条件 64 条独立 rollout，运行 80 轮。

## 结果
| 条件 | 80轮后平均 |p-0.5| | 极端比例 |
|---|---:|---:|
| 只吃自己 | 0.2540 | 48.44% |
| 自己+随机中性块 | 0.1022 | 0% |
| 自己+硬镜像块 | 0.0195 | 0% |

硬镜像相对“只吃自己”降低最终平均偏离约 92.3%，相对随机中性块降低约 80.9%。

在硬镜像条件内部，模型先生成自己的 8-token 块后，平均 |p-0.5| 为 0.06595；随后加入镜像块后降到 0.01854，单轮平均回正约 71.9%。该模式在后期轮次仍保持。

## 当前支持
这个微型构造证明：对于一个会从上下文估计当前生成分布的模型，可以先让模型暴露自身局部命中偏好，再构造严格反向的第二段上下文，从而在递归自喂过程中显著抵消分布漂移。

它支持“输出分布 → 镜像内容 → 两段拼接 → 下一轮重新拟合”的技术可行性。

## 边界
这是一个刻意简化的分布推断世界。这里的“完美镜像”有已知中心 p*=0.5，因此可以精确构造。它尚未建立自然语言模型中应镜像的真实变量，也未证明 token 频率镜像等同于推理规则/continuation geometry 的镜像。

下一步真正困难的问题是：在自然语言或推理任务中，找到可定义的参考中心与可逆镜像算子，而不是继续证明这个二元玩具能够被平衡。
