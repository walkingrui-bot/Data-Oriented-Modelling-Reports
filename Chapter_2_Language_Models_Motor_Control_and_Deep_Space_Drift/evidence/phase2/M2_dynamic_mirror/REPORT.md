# 第三阶段：动态思考链逐 token 镜像控制
## Tokenwise Mirror Control for Self-Conditioned Reasoning

日期：2026-09-25

## 1. 工程问题

前两阶段已经建立两条镜像路线：

- **内容镜像**：在语言出口构造互补内容，使它重新进入上下文后稳定后续生成；
- **状态镜像**：给当前内部生成状态构造镜像状态，用主状态与镜像状态的中点估计局部稳定生成中心。

第三阶段的问题更严格：

> 思考链不是一次生成以后才整体漂移。模型每生成一个 token，这个 token 都会立刻被重新读回，成为下一次生成函数的条件。能否在这个逐 token 自回灌闭环里持续做小幅镜像纠偏，使微小偏航不能一层层写进后续历史？

本轮构造 **Tokenwise Mirror Controller (TMC)**。

## 2. 控制方程

当前生成状态为 `h_t`，学习到的镜像算子为 `M(h_t)`。

主模型 logits：

`l_t = L(h_t)`

镜像 logits：

`l_t^mirror = L(M(h_t))`

逐 token 控制使用：

`l_t^ctrl = (1-lambda_t) l_t + lambda_t l_t^mirror`

其中 `0 <= lambda_t <= 0.5`。

`lambda=0` 是自由生成；
`lambda=0.5` 是主状态和镜像状态完全对称融合。

生成出的 token `y_t` 随即重新进入下一状态，因此闭环是：

`h_t -> mirror correction -> y_t -> read-back -> h_(t+1) -> mirror correction -> ...`

镜像控制器运行时没有标准下一 token，也没有参考输出分布。

## 3. 最小世界

构造一个 24 维非线性自回灌生成系统：

- 稳定任务/语义状态持续缓慢运动；
- 自生成 token 被立即读回；
- token 读回产生小的方向性状态偏移；
- 偏移改变下一 token 分布；
- 新分布又改变下一次被读回的 token，因此产生自强化闭环。

稳定参考生成函数由同一任务状态、零偏航条件给出，仅用于实验端测量，不提供给控制器。

镜像网络只在成对的对称状态上训练：

`M(h_plus) ≈ h_minus`
`M(h_minus) ≈ h_plus`

并加入：

`M(M(h)) ≈ h`

的 involution 约束。

本轮 mirror-state held-out MSE = **0.0774**；
involution MSE = **0.0290**。

## 4. 主实验一：纠偏频率扫描

这是本轮最直接回答“每读一个 token 都会不会继续积累偏航”的实验。

12 条配对独立轨迹，每条 3,200 个自回归 token。
所有条件使用相同的初始任务状态分布，统计单位是**完整轨迹**，不是 token。

分别每 1 / 2 / 4 / 8 / 16 个 token 使用一次镜像；另有完全自由生成对照。

末段 TV（每条轨迹最后 800 token 的均值，再在轨迹层统计）：

| 校正间隔 | late TV | trajectory-bootstrap 95% CI | 相对 free 降低 |
|---|---:|---:|---:|
| 每 1 token | 0.0675 | [0.0583, 0.0767] | 83.6% |
| 每 2 token | 0.2340 | [0.2191, 0.2479] | 42.8% |
| 每 4 token | 0.3277 | [0.3102, 0.3445] | 20.1% |
| 每 8 token | 0.3671 | [0.3489, 0.3844] | 10.9% |
| 每 16 token | 0.3962 | [0.3739, 0.4149] | 3.4% |
| 自由生成 | 0.4155 | [0.3907, 0.4369] | - |

最强结果：

- 自由生成 late TV = **0.4155**
- 每 token 镜像 late TV = **0.0675**
- 配对相对降低 = **83.6%**
- 轨迹 bootstrap 95% CI = **[81.2%, 85.9%]**

更关键的是频率梯度：

`1 -> 2 -> 4 -> 8 -> 16 -> free`

对应 late TV 近似：

`0.067 -> 0.234 -> 0.328 -> 0.367 -> 0.396 -> 0.415`

因此“偶尔照镜子”与“每一步都控制”不是等价的。

每 16 token 才校正一次的配对降低只有约 3.4%，其 bootstrap CI 已跨 0；每 token 校正则稳定降低约 84%。

这支持本轮的工程判断：

> **在自回灌生成中，偏航可以作为大量微小 read-back 更新持续累积；如果控制目标是生成函数本身，控制周期需要接近状态被重新写入的周期。**

## 5. 主实验二：逐 token 控制剂量

如果效果只是“镜像开/关”的离散技巧，那么改变每次校正幅度不一定产生规则响应。

10 条独立轨迹、每条 3,000 token，所有步都使用镜像，但改变 `lambda`：

| 每 token 镜像剂量 lambda | late TV | trajectory-bootstrap 95% CI |
|---:|---:|---:|
| 0.00 | 0.4167 | [0.3871, 0.4428] |
| 0.05 | 0.3922 | [0.3691, 0.4144] |
| 0.10 | 0.3460 | [0.3170, 0.3718] |
| 0.20 | 0.2672 | [0.2516, 0.2809] |
| 0.35 | 0.1562 | [0.1446, 0.1704] |
| 0.50 | 0.0766 | [0.0633, 0.0904] |

得到近似单调剂量—反应：

`lambda: 0 -> .05 -> .10 -> .20 -> .35 -> .50`

`late TV: .417 -> .392 -> .346 -> .267 -> .156 -> .077`

因此并不需要把系统硬重置到镜像中点才能产生稳定作用。许多很小的逐 token 修正也会累积成明显的长期稳定效应。

这提供了一个真正可工程调节的参数，而不是二元开关。

## 6. 主实验三：强扰动下的动态控制

6 条独立 8,000-step 轨迹，在 2,000 / 4,000 / 6,000 步注入强状态扰动。

主要结果：

| 条件 | late TV | late KL | 高漂移 TV>0.1 比例 | shock 后 250-step TV |
|---|---:|---:|---:|---:|
| free | 0.4244 | 0.5581 | 99.4% | 0.4116 |
| periodic8 | 0.3828 | 0.4849 | 91.6% | 0.3765 |
| adaptive | 0.0508 | 0.0083 | 10.4% | 0.0658 |
| every_token | 0.0525 | 0.0095 | 1.7% | 0.0661 |

自由生成和每 8 token 镜像都会重新进入高漂移区。

逐 token 镜像在强扰动后仍把 output-distribution TV 压在约 0.06 左右；自适应镜像也达到相近量级。

这里有一个重要边界：

**输出生成函数被稳定，并不等价于所有内部隐藏偏移都被修复。**

本轮控制主要作用在当前 continuation distribution，并通过更稳定的 token read-back 间接抑制后续恶化。隐藏 drift diagnostic 在强扰动世界中仍可能保持较大。因此 TMC 当前应称为**生成函数控制器**，不是“把内部状态恢复到唯一真状态”的装置。

## 7. 第三阶段得到的新工程对象

### 7.1 Mirror Disagreement

`delta_t = D(P_main, P_mirror)`

它可以作为当前生成状态不对称程度的在线传感器。

### 7.2 Tokenwise Mirror Dose

`lambda_t`

决定本次 read-back 之前需要抵消多少不对称生成分量。

### 7.3 Correction Cadence

本轮第一次显示：**控制频率本身就是核心工程变量。**

如果系统每 token 都重新读取自己的输出，那么每 8 或 16 token 才纠偏一次可能已经太慢。

### 7.4 Dynamic CoT stabilization

新的闭环不是：

`生成一整段 -> 判断错没错 -> 重写`

而是：

`生成一个 token -> 测镜像不对称 -> 小幅纠偏 -> token 回灌 -> 再测 -> ...`

因此可以在可见错误形成以前持续控制生成函数。

## 8. 与前两阶段合并

现在已有三层镜像路线：

1. **内容镜像**：在语言空间构造互补内容并重新进入上下文。
2. **状态镜像**：在内部生成状态空间构造镜像，估计局部稳定中心与偏航方向。
3. **逐 token 动态镜像**：在每次 output -> read-back 循环中持续小幅抵消偏航，使误差不容易被写入下一轮生成条件。

它们可以统一成：

`Mirror Stabilization of the Generative Process`

第三阶段最核心的结果不是“镜像平均能提高一个分数”，而是：

> **控制频率与自回灌频率之间存在直接关系。一个每 token 更新自己的生成系统，需要接近 token 级的生成函数稳定器；稀疏纠偏无法等价替代连续微校正。**

## 9. 与 GCM 的工程拼接

GCM 给出：

- Generation-State Readout：现在正形成什么未来；
- Future Causal Influence：哪些历史真正塑造这个未来；
- Control Gain：在哪里仍然有杠杆。

TMC/MGC 再补：

- Mirror Disagreement：偏到哪一侧；
- Mirror Direction：反方向在哪里；
- Tokenwise Dose：这一拍拉多少；
- Correction Cadence：多久拉一次。

因此可以形成真正的在线控制栈：

`observe -> locate cause -> locate leverage -> estimate mirror -> apply small correction -> generate -> read back -> repeat`

Attention 只需要作为其中一个内部路由信号，不再承担全部“模型到底在干什么”的解释和控制职责。

## 10. 当前结论

本轮是 synthetic proof-of-mechanism，不是现实大模型的直接效果估计。

它建立的是一个具体工程可能性：

> **在每个 token 都重新进入下一步条件的自回归系统中，学习到的镜像状态可以被用于逐 token 稳定 continuation distribution；控制越稀疏，漂移越明显；逐 token 小幅镜像具有明确的剂量—反应和频率—反应关系。**

下一阶段接真实 LLM 时，最关键的不再是证明“镜像平均有用”，而是用 GCM 先找出具有高 Control Gain 的内部位置，再在该位置训练/部署局部镜像控制器，测真实长 CoT 的生成约束指纹、未来分布漂移和恢复能力。
