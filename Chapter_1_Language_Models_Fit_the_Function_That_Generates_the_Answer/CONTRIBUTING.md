# Feedback and Replication

Feedback is welcome through repository issues or walkingrui@gmail.com.

For an experimental question, include the release version, experiment ID, evidence path, and specific result being discussed. A useful replication record includes the environment, command, configuration, random seeds, generated outputs, and the comparison with the archived result.

Alternative mechanisms and discriminating experiments are welcome. Explain the mechanism, the measurable prediction, and the observation that would distinguish it from the current account.

Keep original evidence intact and put new runs in a separate directory. Proposed edits to findings should connect each numerical change to its supporting artifact and update the change history.
