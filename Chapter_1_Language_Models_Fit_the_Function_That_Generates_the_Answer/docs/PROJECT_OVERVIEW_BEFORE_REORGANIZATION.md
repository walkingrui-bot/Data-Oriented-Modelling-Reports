## Language Models Fit the Function That Generates the Answer

**A language model is fitting the function that will generate its answer.**

The problem, context, and computational history assemble a particular way of generating. Thinking brings that function into operation; each output gives it something new to encounter. These two reports go after the generator behind the words, then build instruments and controls to get hold of it.

Phase 1 follows relational fingerprints, transferred rules, self-writing, and a million-step constructed world. Phase 2 finds the source of a future fork before the outputs split, maps where the future can still be changed, and uses mirrors to offset preference and control drift. The methods, numbers, and experiment folders are right behind the story.

This is a **self-directed personal-interest research project, conducted without academic supervision or institutional research guidance**. It is maintained as a living research record. Read the [project information](../PROJECT_INFORMATION.md) for its nature and update policy.

## Check the evidence

From the repository root, using Python 3.9 or newer:

```bash
python scripts/verify_release.py
python audit/recalculate.py
python audit/recalculate_phase2.py
```

For the per-episode RTG outputs, `python scripts/prepare_evidence.py` restores the compressed source file and checks its original hash. Each experiment's reproduction route is documented separately.
