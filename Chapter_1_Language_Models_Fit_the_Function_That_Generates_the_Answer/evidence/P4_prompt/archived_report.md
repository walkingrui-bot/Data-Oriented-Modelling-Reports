# 提示词路径与中层注入等价性：四层微型 Transformer 机制实验

日期：2026-09-25

## 问题
检验两条路径是否可能作用于同一个后续生成状态：

1. 入口路径：前置提示词从输入进入，经过若干层正常加工后改变输出分布。
2. 中层路径：删去该提示词，在中间层直接加入“有提示 vs 无提示”造成的真实状态位移，观察后半段输出是否逼近有提示条件。

这不是 Claude 复现，而是一个最小构造实验，用来检验该机制在小型因果 Transformer 中是否可成立。

## 模型与任务
- 4 层 causal Transformer
- hidden size 24，3 heads
- 4 个前缀位置
- 16 类内容
- 每类内容有 A/B 两个等义输出变体
- STYLE 前缀使 A 变体目标概率约为 0.9；NEUTRAL 前缀使 A 变体目标概率约为 0.1
- 训练 45 个 mini-batch steps
- 3 个随机种子

训练后：
- STYLE 条件下 A 概率：0.888 / 0.889 / 0.895
- NEUTRAL 条件下 A 概率：0.138 / 0.160 / 0.196

## 注入方法
在内容 0–7 上估计每层最后位置的平均提示词状态位移：

Δ_k = mean[h_k(STYLE) - h_k(NEUTRAL)]

然后在完全未用于估计 Δ 的内容 8–15 上：
- 运行 NEUTRAL 分支；
- 在第 k 层后把 Δ_k 加到最后位置；
- 比较输出分布与真实 STYLE 分支的总变差距离（TV）；
- 同时使用同范数随机方向作为控制。

## 三个 seed 的 TV 结果

| 注入位置 | 基线 NEUTRAL→STYLE TV | 真实提示位移注入后 TV | 同范数随机方向平均 TV |
|---|---:|---:|---:|
| 第1层后 | 0.721 | 0.711 | 0.716 |
| 第2层后 | 0.721 | 0.674 | 0.709 |
| 第3层后 | 0.721 | 0.472 | 0.662 |
| 第4层后 | 0.721 | 0.218 | 0.634 |

第 4 层真实位移平均消除了约 70% 的“无提示 vs 有提示”分布差，而随机同范数方向只消除约 12%。

第 4 层注入后的 A 概率分别为：
- seed 0: 0.691
- seed 1: 0.700
- seed 2: 0.648

真实 STYLE 条件约为 0.89；NEUTRAL 条件约为 0.14–0.20。

## 剂量—反应与反向干预（seed 0，第4层）

从 NEUTRAL 状态加入 scale × Δ：

| scale | A 概率 |
|---:|---:|
| -1.0 | 0.068 |
| -0.5 | 0.095 |
| 0 | 0.174 |
| 0.5 | 0.400 |
| 1.0 | 0.691 |
| 1.5 | 0.829 |
| 2.0 | 0.880 |

反向地，从 STYLE 状态减去 scale × Δ：

| scale | A 概率 |
|---:|---:|
| 0 | 0.868 |
| 0.5 | 0.664 |
| 1.0 | 0.363 |
| 1.5 | 0.204 |
| 2.0 | 0.137 |

表现出清晰、双向、近单调的剂量—反应关系。

## 当前结论
该最小实验支持一个构造性命题：在这个四层模型中，前置提示词经过若干层加工后形成了一个可跨内容泛化的状态位移；在较晚层直接施加该位移，可以在没有原提示词的情况下重现大部分提示词造成的输出分布偏置。

结果更符合“入口正常加工”和“中途状态定位”是到达相近后续生成区域的两条路径，而不是“任意内部扰动都能改输出”。明显的层依赖也符合：越靠后，提示词对当前生成规则的加工后果越成形，因而越适合被直接注入。

## 证据边界
该实验是一个合成任务上的构造性验证，不等价于 Claude 内部机制复现。它支持“prompt conditioning 与 mid-layer steering 可以在一个真实小型 Transformer 中实现功能等价”的可行性；Claude 上是否采用同一机制，需要在实际模型或可访问的近似模型上进一步做配对路径实验。
