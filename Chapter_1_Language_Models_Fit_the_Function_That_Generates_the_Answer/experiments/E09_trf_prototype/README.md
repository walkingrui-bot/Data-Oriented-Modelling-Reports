# E09 Qualification of the TRF neural prototype

[Experiment index](../README.md)

The prototype sustained temporal persistence and long-distance cross-event flow. Its FULL-versus-shuffle structural-language advantage varied across runs.

## Method

TRF-v0.1R assessed temporal persistence, cross-event flow and structural-language performance against position shuffles over three seeds, 24 lives and 480 events.

## Interpretation

Persistent activity and cross-event flow were established engineering results. Order sensitivity supplied a separate test of learned language structure.
