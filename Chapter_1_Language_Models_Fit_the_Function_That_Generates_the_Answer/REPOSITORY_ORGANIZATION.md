# Repository organization

The repository is arranged as four chapters. Chapter 3 is **Machine Learning Epidemiology**; its research report and Engineer’s Edition live together. Chapter 4, **Data Zoo**, collects independently versioned subreports.

| Folder | Contents |
| --- | --- |
| [Chapter_1_Language_Models_Fit_the_Function_That_Generates_the_Answer](README.md) | Chapter 1 report, E01–E27, their evidence and original source report; shared project records and combined Chapters 1–2 indexes |
| [Chapter_2_Language_Models_Motor_Control_and_Deep_Space_Drift](../Chapter_2_Language_Models_Motor_Control_and_Deep_Space_Drift/README.md) | **Language Models: Motor Control and Deep-Space Drift**, E28–E39, their evidence, original source report and Phase 2 audit records |
| [Chapter_3_Machine_Learning_Epidemiology](../Chapter_3_Machine_Learning_Epidemiology/README.md) | Chapter 3 research v1.9, Engineer’s Edition v0.6, both evidence collections, reviewed combined description and inventory |
| [Chapter_4_Data_Zoo](../Chapter_4_Data_Zoo/README.md) | Data Zoo catalog and Human Learning and Sensorimotor Geometry Subreport 2, English v1.0; report, figures, sources and evidence |

[ORIGINAL_PATH_MAP.csv](ORIGINAL_PATH_MAP.csv) maps every file from the previous layout to its current path. Each original file has one destination. Shared records are not duplicate experiments; they remain together under Chapter 1.

The 26 September reorganization moved original evidence, source files, model files, data, ZIP archives and Word reports without changing their content. Existing historical manifests, recorded paths and checksums refer to the layout in which they were created. Use the path map to locate them in this reading layout. English navigation links are adjusted for the new locations; scientific statements are not re-evaluated.

For exact archival reproduction, use [the original Chapters 1–2 v0.1.0 snapshot](https://github.com/walkingrui-bot/Data-Oriented-Modelling-Reports/tree/v0.1.0) and [the original Chapter 3 combined archive](https://doi.org/10.5281/zenodo.22983593). Historical integrity scripts and manifests apply to those fixed snapshots, not to newly edited navigation pages. No scientific experiments or integrity suites were rerun during this reorganization.

Project-wide information is in [PROJECT_INFORMATION.md](PROJECT_INFORMATION.md), [CITATION.md](CITATION.md), [SOURCE_NOTES.md](SOURCE_NOTES.md), and the original combined metadata/catalog files beside them. The legacy issue template is retained in [.github/ISSUE_TEMPLATE/research-feedback.md](.github/ISSUE_TEMPLATE/research-feedback.md) as a reference template.
