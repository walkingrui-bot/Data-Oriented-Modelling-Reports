# Repository organization

The repository is arranged as three chapters. Chapter 3 is **Machine Learning Epidemiology**; its research report and Engineer’s Edition live together.

| Folder | Contents |
| --- | --- |
| [Chapter_1_Language_Models_Fit_the_Function_That_Generates_the_Answer](README.md) | Chapter 1 report, E01–E27, their evidence and original source report; shared project records and combined Chapters 1–2 indexes |
| [Chapter_2_Read_the_Future_Then_Change_It](../Chapter_2_Read_the_Future_Then_Change_It/README.md) | Chapter 2 report, E28–E39, their evidence, original source report and Phase 2 audit records |
| [Chapter_3_Machine_Learning_Epidemiology](../Chapter_3_Machine_Learning_Epidemiology/README.md) | Chapter 3 research v1.9, Engineer’s Edition v0.6, both evidence collections, reviewed combined description and inventory |

[ORIGINAL_PATH_MAP.csv](ORIGINAL_PATH_MAP.csv) maps every file from the previous layout to its current path. Each original file has one destination. Shared records are not duplicate experiments; they remain together under Chapter 1.

Original evidence, source files, model files, data, ZIP archives and Word reports are moved without changing their content. Existing historical manifests, recorded paths and checksums refer to the layout in which they were created. Use the path map to locate them in this reading layout. English navigation links are adjusted for the new locations; scientific statements are not re-evaluated.

For exact archival reproduction, use [the original Chapters 1–2 v0.1.0 snapshot](https://github.com/walkingrui-bot/biosphere-3-public-reports/tree/v0.1.0) and [the original Chapter 3 combined archive](https://doi.org/10.5281/zenodo.22983593). Historical integrity scripts and manifests apply to those fixed snapshots, not to newly edited navigation pages. No scientific experiments or integrity suites were rerun during this reorganization.

Project-wide information is in [PROJECT_INFORMATION.md](PROJECT_INFORMATION.md), [CITATION.md](CITATION.md), [SOURCE_NOTES.md](SOURCE_NOTES.md), and the original combined metadata/catalog files beside them. The legacy issue template is retained in [.github/ISSUE_TEMPLATE/research-feedback.md](.github/ISSUE_TEMPLATE/research-feedback.md) as a reference template.
