# Modelling Hypothesized Mechanisms Underlying Data

**Data-Oriented Modelling · Chapter 5 · Report 03 · English publication v1.0 · 2026-09-28**

This report studies how assumptions about data generation, observation, geometry and valid states determine useful modelling operations. Twelve named experiments connect attention-induced geometry changes, local-scale relations, training coverage, discrete graph constraints and validation across four additional datasets. The resulting procedure combines mechanism-guided candidate selection with a validation probe within the training data.

Read the [full English report](REPORT_EN.md) or download the [Word edition](Data_Oriented_Modelling_03_Modelling_Hypothesized_Mechanisms_Underlying_Data_EN_v1.0.docx). Both editions contain all 25 figures, 19 numbered research tables, a glossary and 15 displayed equations. The Word report has 41 pages and uses plain report formatting.
