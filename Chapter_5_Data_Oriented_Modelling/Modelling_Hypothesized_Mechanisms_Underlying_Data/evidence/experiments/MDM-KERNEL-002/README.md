# MDM-KERNEL-002

This experiment compares relation operators for withheld-edge recovery in the Karate, Davis Southern Women and Florentine networks. The CSVs provide 100 recorded splits per graph and candidate, an additional Davis path-order scan and supplementary one-mode operators. Summary files aggregate these outcomes; graph_diagnostics.csv records graph-level properties.

experiment_protocol.py specifies the network sources, edge withholding, candidate ranking and evaluation procedure as a protocol sketch. The published CSVs support recalculating the recorded means for Tables 13–14. The separate Karate AUC 0.792 comparison is represented by its report record, while the supplementary CSV covers resource allocation, preferential attachment, geodesic closure and Katz scores.
