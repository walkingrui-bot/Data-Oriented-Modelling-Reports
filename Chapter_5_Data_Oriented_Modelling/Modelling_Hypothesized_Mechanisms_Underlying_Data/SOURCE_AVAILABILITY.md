# Source availability

The publication contains authored results and scientific records. Provider datasets are loaded separately through the named software packages for reproduction.

| Research component | Source accessed by the recorded work | Published evidence |
| --- | --- | --- |
| Early tabular comparisons | Iris, Wine, Breast Cancer, Digits and Diabetes, as identified in the report | Report methods, numerical tables and figures |
| Graph operator comparisons | NetworkX Karate Club, Davis Southern Women and Florentine Families networks | Aggregate graph diagnostics, per-split evaluation metrics, summaries and protocol sketch |
| Group choice | statsmodels Travel Mode Choice | Per-split NLL and accuracy, recorded design diagnostics and analysis code |
| Coverage comparison | statsmodels Engel household expenditure | Per-split RMSE and macro-RMSE, nested selection outcomes, diagnostics and code |
| Count likelihood | statsmodels RAND Health Insurance Experiment | Per-split deviance, RMSE and MAE, aggregate diagnostics and code |
| Relation recovery | NetworkX Les Misérables coappearance graph from Knuth's Stanford GraphBase | Per-split AUC, aggregate graph diagnostics and code |

The provider sources retain their attribution and reuse terms. The requirements for reproducing the final staged validation are listed in its recorded environment_versions.txt file. Source records in this publication are aggregate measurements, plotted results and analysis outputs.
