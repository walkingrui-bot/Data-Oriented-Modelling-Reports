All report figures are included. Four figures are redrawn for clear English presentation: the conceptual overview (Figure 1), the CG-004 moment-approximation error plot (Figure 11, recomputed from the supplied grid), and the CG-022/CG-024 objective comparisons (Figures 75 and 85, using supplied aggregate results). Other figure bytes are preserved. The script render_publication_figures.py reproduces these four figures without model execution.

The [verification notes](verification/README.md) distinguish current checks from archived experiment verification. The [data availability statement](DATA_AVAILABILITY.md) defines the release boundary.
