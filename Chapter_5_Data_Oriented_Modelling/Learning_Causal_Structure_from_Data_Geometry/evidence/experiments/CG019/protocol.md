# CG-019 Cross-Question World Reuse Stress Test

CG-019 reuses the six frozen synthetic mechanism checkpoints from CG-018: Mechanism Blank and Mechanism Feedback, seeds 11/22/33. No model is retrained, extended, or selected in this experiment. The held-out synthetic test panel contains 600 task instances from 100 parameter groups, with three observationally equivalent causal worlds and support/no-support conditions retained exactly as in CG-018.

The experiment asks whether the generated relation matrices can be reused for operations that were absent from training. Training in CG-018 used one positive unit intervention on a single query target. CG-019 introduces two query families.

**Novel double interventions.** For each frozen test context, all three unordered pairs of variables are simultaneously clamped under four sign patterns: (+1,+1), (+1,-1), (-1,+1), and (-1,-1). This creates 12 unseen query forms per test task, or 7,200 query evaluations per checkpoint. The mechanism condition edits the appropriate equation rows and solves the generated relation system. The answer-superposition control uses the same candidate weights and the same three stored single-do consequences, linearly combines two single-do answers, and then overwrites the clamped coordinates. Thus both routes use the same trained checkpoint and candidate information; they differ in whether the generated relations are actually used to recompute the joint intervention.

**Edge-deletion queries.** Each true three-variable world contains exactly two nonzero directed edges. For each held-out task and each true edge r<-s, the evaluation instruction deletes that edge and then applies do(X_s=1). Ground-truth consequences are computed exactly from the edited structural equation. The same coordinate is set to zero in every generated candidate relation matrix before solving. The true graph is used only to define the held-out edit instruction and exact evaluation consequence; it is not supplied during model generation or training. Each checkpoint receives 1,200 such requested-edge queries.

The initial planned control leaves the generated relation matrix unchanged despite the deletion request. After the large initial effect was observed, an additional localization control was added: for every requested true edge, each of the four off-diagonal coordinates absent from the true graph is deleted in turn, producing 4,800 wrong-coordinate control evaluations per checkpoint. This distinguishes semantic coordinate reuse from a generic benefit of weakening a generated matrix.

All mixture NLL calculations retain the CG-017/018 fixed isotropic standard deviation 0.15. Mean MSE and candidate coverage use the existing definitions; coverage requires RMS distance <=0.20 and candidate weight >=0.10. For paired robustness checks, query-level scores are first averaged within each of the 100 independent held-out parameter groups and then averaged across the three seeds. Ten thousand group bootstraps provide 95% intervals. Reported group-positive fractions are the fraction of the 100 parameter groups in which the specified mechanism operation improves the paired metric.
