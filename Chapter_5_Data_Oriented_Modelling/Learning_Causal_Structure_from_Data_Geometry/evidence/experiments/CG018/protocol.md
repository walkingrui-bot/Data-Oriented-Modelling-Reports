# CG-018 Generated Relations and Internal Mechanism Simulation

Frozen before training on 2026-09-27. Two added architectures, three seeds, the
same synthetic and five Sachs target-held-out panels as CG-017: 36 new fits.
CG-017's four existing routes are retained as frozen references.

Each new architecture generates three relation matrices B (zero diagonal, row
absolute sum at most .95), candidate weights, and (for Sachs) affine offsets.
It solves the generated simultaneous equations under a query clamp or observed
variable clamps. Thus outputs are produced by internally generated mechanisms.
Both models use 48 hidden units and four GRU updates. Mechanism-Blank feeds zeros;
Mechanism-Feedback projects generated relations, offsets, weights, and simulated
consequences into 16 dimensions and reinjects them. All objects are generated by
the model; training uses final prediction loss only.

Synthetic mechanism generation excludes the query target. Every update simulates
all three do-targets, so one generated candidate can answer multiple queries.
The supplied support intervention is included in context. Training uses exactly
the original query per parameter group. Expanded evaluation scores all three
queries in test groups, including the two alternate queries. True mechanism
matrices are reserved for descriptive evaluation and illustrations.

Sachs uses exactly the original cells, masks, splits, and preprocessing. Generated
affine relations solve missing values with the observed values clamped. These are
learned local computational mechanisms for conditional prediction. Quantitative
biology interpretation follows from the measured prediction task.

Training: seeds11/22/33, Adam .002, 1200 updates batch96 synthetic, 800 updates
batch64 real; dev selection every100 steps, same batch RNG as CG-017. Record total
parameters and fit time. Principal feedback comparison is between the two new
architectures; comparison with old heads also includes their representational
and parameter differences.

After training, on Mechanism-Feedback: cut explicit feedback; zero simulated
consequences inside the feedback; reverse the largest-magnitude edge of the
highest-weight candidate at step2, then freely regenerate; no-op. Measure final
loss, prediction displacement, and subsequent relation displacement. Record
unsupervised intermediate trajectories. No result-dependent training extension.

Report both panels, every seed and target, candidate examples selected by true
world separation, and matched architecture feedback comparisons. External raw
measurements remain outside the deliverable evidence archive.
