# Learning Causal Structure from Data Geometry

Where Causal Information Resides and How Models Preserve It

Data-Oriented Modelling · Chapter 5 · Report 02 · Causal inference feature · English v1.0 · 28 September 2026

This report asks where identifiable causal information occurs in data geometry, how learning can preserve or distort it, and how retained structure can be tested through new operations. Twenty-four experiments connect identifiability and local geometry with source transfer, intervention responses, representation compression and executable candidate mechanisms.

[English report](REPORT_EN.md) · [Word edition](Data_Oriented_Modelling_02_Learning_Causal_Structure_from_Data_Geometry_EN_v1.0.docx) · [Evidence index](EVIDENCE_INDEX.md) · [Reproduction guide](REPRODUCTION.md) · [Data availability](DATA_AVAILABILITY.md)

The early experiments locate direction-breaking information under specified assumptions. Real-data studies show that compression, stable scores and predictive gains need not preserve local causal roles or transport validity. The later synthetic experiments test generated relations through cross-query reuse, edits, evidence updates, long rollout and sequential interventions. Their scope is explicit: useful learned mechanisms in the tested systems do not establish a universal causal learner.

The edition includes all 89 report figures and 55 original tables, with an executive summary, experiment map, terminology and practical checklist. Results and limitations are presented together. The evidence index distinguishes partial early records from later code and checkpoint records. External provider measurements are excluded.
