# Report 02 downloads

The publication and evidence packages are distributed as 8 MiB volumes. The downloader assembles each standard ZIP and verifies both the volumes and the complete archive against SHA-256. The assembled files are byte-for-byte identical to the English v1.0 packages.

[Read the report](../Learning_Causal_Structure_from_Data_Geometry/README.md) · [Download Word](../Learning_Causal_Structure_from_Data_Geometry/Data_Oriented_Modelling_02_Learning_Causal_Structure_from_Data_Geometry_EN_v1.0.docx)

## Download and assemble

Save [download_report_02.py](https://raw.githubusercontent.com/walkingrui-bot/Data-Oriented-Modelling-Reports/main/Chapter_5_Data_Oriented_Modelling/releases/download_report_02.py), then run:

```bash
python3 download_report_02.py
```

The script uses the Python standard library and writes the two verified ZIPs into the current directory. To select one package, add `--package publication` or `--package evidence`. For a local repository copy, the script reads the included volumes directly.

Individual volumes are also linked below. Concatenate them in numerical order to reconstruct the corresponding ZIP.
