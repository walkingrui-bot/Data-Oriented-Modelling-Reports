Report 01 develops a data-oriented modelling framework through synthetic mechanism comparisons, tracking and observation processes, resource-aware computation, empirical graph geometry and distributed state coordination.

Downloads: [publication package](releases/Data_Oriented_Modelling_01_Publication_v1.0_20260928.zip) · [evidence package](releases/Data_Oriented_Modelling_01_Evidence_v1.0_20260928.zip).

Report 02 studies the location and preservation of causal information in data geometry and machine learning, from identifiability to executable intervention models. [Publication package](releases/REPORT_02_DOWNLOADS.md#publication-package) · [Evidence package](releases/REPORT_02_DOWNLOADS.md#evidence-package).

Report 03 develops mechanism-guided modelling through local-scale relations, training coverage, graph state constraints and precommitted validation. [Publication package](releases/Data_Oriented_Modelling_03_Publication_v1.0_20260928.zip) · [Evidence package](releases/Data_Oriented_Modelling_03_Evidence_v1.0_20260928.zip).
