# Data-Oriented Modelling: Heterogeneous Data and General Data Intelligence

**Chapter 5 — Data-Oriented Modelling · Report 01 · English publication v1.0 · 2026-09-28**

This report studies how data-generating mechanisms and observation processes inform predictive states, memory, parameter sharing, source-native representations and distributed coordination. Its evidence combines controlled simulations, measured real-graph geometry and a frozen authored-corpus coordination workload.

Read the [full English report](REPORT_EN.md) or download the [Word edition](Data_Oriented_Modelling_01_Heterogeneous_Data_and_General_Data_Intelligence_EN_v1.0.docx). The report includes 84 figures and 94 tables. The Word edition uses plain report formatting without headers or footers.
