# 003 — Dimension, memory and law heterogeneity

Synthetic experiment.

A factorial design crosses latent dimension 3 or 14, memory order 1 or 4, and one or four transition laws. Two optimization seeds compare a shared block with a routed model under nearly matched total parameter budgets. Additional comparisons vary expert capacity and supply oracle routing. Read the oracle rows together with their larger parameter budgets.

Read [report section 5.1](../../../REPORT_EN.md#51-world-data-geometry-003-dimension-memory-and-transition-law-heterogeneity) for the full methods, comparisons and interpretation.
