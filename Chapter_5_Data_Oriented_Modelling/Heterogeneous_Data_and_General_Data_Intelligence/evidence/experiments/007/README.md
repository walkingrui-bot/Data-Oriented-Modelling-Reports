# 007 — Hidden manifolds and partition discovery

Synthetic experiment.

A two-turn manifold is embedded in 12 observed dimensions; a hidden periodic phase controls the future transition. Observation clusters, predictive-Jacobian clusters and communities of a training-transfer graph define alternative partitions. Hidden phase supplies an evaluation reference. The archive includes hard partitions and shared predictors with local residuals.

Read [report section 5.5](../../../REPORT_EN.md#55-hidden-manifold-partition-007-discovering-predictive-geometry-without-latent-coordinates) for the full methods, comparisons and interpretation.
