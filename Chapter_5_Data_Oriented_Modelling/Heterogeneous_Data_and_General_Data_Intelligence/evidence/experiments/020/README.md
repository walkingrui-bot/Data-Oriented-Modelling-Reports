# 020 — Curvature and slow-state components

Synthetic experiment.

A curvature feature channel and a slow predictive-state component are evaluated individually and together while the shared architecture is retained. Candidate screening is followed by a second seed; the reported comparison averages the screening and additional seeds. These are two-seed regression comparisons with stated intact-performance and module-removal criteria.

Read [report section 7.6](../../../REPORT_EN.md#76-targeted-failure-repair-020-curvature--slow-state-repair) for the full methods, comparisons and interpretation.
