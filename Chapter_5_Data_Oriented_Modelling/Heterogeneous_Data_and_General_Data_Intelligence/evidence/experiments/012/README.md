# 012 — Relational carrier states

Synthetic experiment.

Persistent slots are augmented with directed relation messages and a shared recurrent residual pathway. Regular and irregular sampling conditions are evaluated, including a clock-aware assimilation variant. The relation audit compares learned message strengths with simulator events; it measures correspondence under the specified probe.

Read [report section 6.3](../../../REPORT_EN.md#63-dynamic-carrier-graph-012-relational-state-transfer-for-forecasting) for the full methods, comparisons and interpretation.
