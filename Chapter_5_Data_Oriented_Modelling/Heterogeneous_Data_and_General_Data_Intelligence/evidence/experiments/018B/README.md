# 018B — Integrated resource-aware prediction

Synthetic experiment.

A recurrent predictive state feeds a rank-three shared transition and four overlapping modules coordinated using availability and history. Healthy, depletion and removal conditions have distinct internal dynamics while sharing the external target. Autoregressive rollout, shared-only ablation and redistribution measurements assess the contribution of the module pathway.

Read [report section 7.4](../../../REPORT_EN.md#74-computational-body-world-model-018b-integrated-resource-aware-prediction) for the full methods, comparisons and interpretation.
