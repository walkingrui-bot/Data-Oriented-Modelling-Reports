# 022 — Real graph topology

Empirical derived analysis.

Dolphins, Email-Eu-core, ca-GrQc, Facebook Combined and Cora are compared using degree distributions, local growth, shortest paths and normalized-Laplacian geometry. Distance comparisons use the largest connected component. Directed sources are symmetrized for the topology measurements; sampled clustering and the semantic-alignment calculation are recorded as such.

Read [report section 8.2](../../../REPORT_EN.md#82-real-graph-geometry-022-measured-structure-in-public-graph-data) for the full methods, comparisons and interpretation.
