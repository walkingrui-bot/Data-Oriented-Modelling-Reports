# 015 — Overlapping modules and perturbation training

Synthetic experiment.

A shared dynamic and four overlapping synergies generate a future-transition vector. Hard routing, soft mixtures and shared-residual predictors are compared with transient module-removal training. Matched curriculum controls, output-overlap measurements and router-only adaptation quantify intact performance and response to module removal.

Read [report section 7.1](../../../REPORT_EN.md#71-coordinated-effectors-015-overlapping-modules-and-perturbation-training) for the full methods, comparisons and interpretation.
