# 016 — Availability-aware coordination

Synthetic experiment.

Routing consumes module capacity and unused capacity recovers. The target transition remains fixed while internal availability changes through chronic depletion, a weak module and scheduled outages. Current-availability and history-aware routers are compared with their training curricula. Substitute recruitment is measured through both desired weights and realized load.

Read [report section 7.2](../../../REPORT_EN.md#72-availability-aware-coordination-016-routing-with-observable-resource-state) for the full methods, comparisons and interpretation.
