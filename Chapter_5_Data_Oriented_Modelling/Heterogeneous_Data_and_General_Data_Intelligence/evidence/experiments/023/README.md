# 023 — Graph attributes, time and signed relations

Empirical derived analysis.

Facebook ego-network attributes and circles, Email-Eu-core-temporal events and Bitcoin-OTC trust ratings supply three measured relation layers. Released files contain aggregate alignment, recurrence and sign summaries. The full-span email-window results are retained as an observation-axis comparison; the primary-segment analysis is documented in 024.
