# 019 — Transition-regime stress comparisons

Synthetic experiment.

A fixed architecture is trained separately in smooth, switching, curved and hidden-memory worlds. The evidence retains both the initial availability-gating comparison and a gain-normalized comparison. Report Tables 69–70 and Figures 45–46 use the gain-normalized results, which isolate redistribution more clearly from total transition gain.

Read [report section 7.5](../../../REPORT_EN.md#75-cross-world-stress-battery-019-prediction-across-transition-regimes) for the full methods, comparisons and interpretation.
