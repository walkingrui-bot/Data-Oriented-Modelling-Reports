# 011 — Carrier lifecycle events

Synthetic experiment.

Four possible carriers undergo birth, branching, death and merging under regular or channel-wise irregular sampling. Models include a value-only recurrent baseline, a mask-and-time recurrent model, fixed slots and presence-gated slots. Replicated results separate full-trajectory error, event-specific error and latent-state recovery.

Read [report section 6.2](../../../REPORT_EN.md#62-dynamic-carrier-tracking-011-lifecycle-events-and-irregular-observation) for the full methods, comparisons and interpretation.
