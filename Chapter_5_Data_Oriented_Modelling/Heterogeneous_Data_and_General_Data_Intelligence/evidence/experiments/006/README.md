# 006 — Continuous mechanisms and parameter sharing

Synthetic experiment.

A continuous context changes a local transition operator. Generator contrast, transition width and bridge support are manipulated. Shared prediction, a hard split, soft routing and shared-plus-local residuals are compared. The main report uses the local-block-capacity comparison, in which modular models have larger total capacity. Local-update transfer kernels measure training compatibility.

Read [report section 5.4](../../../REPORT_EN.md#54-data-fusion-partition-006-parameter-sharing-along-a-continuous-mechanism-field) for the full methods, comparisons and interpretation.
