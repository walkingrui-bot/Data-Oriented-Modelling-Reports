# Chapter 0 — The Story Version

**不想看／看不懂报告，就看过来。**

**Don't feel like reading the reports? Getting lost in them? Start here.**

Welcome to the story version of Data-Oriented Modelling. We start with a moving finger, watch a cloud of data appear, stack a few burgers, follow a detective and try on some strange lenses. Along the way, the research questions begin to make sense: what world did we show the model, what did it learn from that world, and what would help it reach a useful answer?

This is the informal entrance to the project. Read it like a conversation. The stories explain why we ran the experiments; links at the end take you to the measurements and reports behind them. The narrative grows as the research grows.
